01 PPO 基础原理

创建日期：2026-11-09
最近更新：2026-11-09

本章解决什么问题

为什么强化学习中的策略更新会过大？PPO 怎样利用固定一批旧策略轨迹，多轮优化新策略而降低更新过猛的风险？

本章从优化直觉解释近端策略优化（Proximal Policy Optimization，PPO）。Actor–Critic、优势估计、非对称 Critic、实际损失与训练诊断见下一章。

快速回顾

PPO 先用当前策略与环境交互，收集状态、动作、奖励和旧策略概率，再从这些样本优化新策略。其 clipped surrogate objective 限制新旧策略概率比对代理目标的贡献，但不严格保证 KL 距离、环境性能或真机安全。

1. 策略和概率比

随机策略写成 πθ(a∣s)，其中 s 是状态、a 是动作、θ 是可训练参数。某动作的优势估计 A^t 表示它相对该状态基准好或差多少。

对旧策略采样的动作，当前新策略的概率比为：

rt(θ)=πθ(at∣st)πθold(at∣st).

若 rt>1，样本动作在新策略下更可能；若 rt<1，更不可能。未裁剪的策略梯度代理项 rtA^t 会按优势调整概率：正优势倾向提高动作概率，负优势倾向降低。

2. 为什么限制一次更新

利用一批固定轨迹重复更新时，策略变化可能很快，采样状态和动作逐渐不再代表新策略访问的分布。过大的更新会让代理目标失去可靠性，甚至令策略性能突然下降。

PPO 采用：

LCLIP(θ)=Et[min(rtA^t,clip(rt,1−ϵ,1+ϵ)A^t)].

ϵ>0 控制概率比裁剪区间的宽度。以 A^t>0 为例，如果概率比高于 1+ϵ，目标不再鼓励它沿这个方向无限增加；负优势时对应地阻止目标通过极端降低概率比继续获取代理收益。

3. 一个数值例子

设 ϵ=0.2 且 A^=2：

比率 r 裁剪比率 未裁剪项 rA^ 参与 min 的裁剪项 有效目标
1.1 1.1 2.2 2.2 2.2
1.5 1.2 3.0 2.4 2.4

在该正优势样本上，旧策略下动作已更受偏好，概率比继续上升不再提高代理目标。但这只是单个样本、一个方向的局部例子，实际优化由很多样本与网络参数共同决定。

4. PPO 实际包含哪些判断

策略更新还依赖优势如何估计、样本如何规范化、每批数据重复训练多少 epoch、value loss 和熵奖励如何设置。策略与价值网络是否共享参数也会改变梯度路径。PPO 并非只有一个裁剪公式。

剪切目标既不是严格 trust region，也不保证每个样本比率都在裁剪范围内；当某一分支的裁剪结果更差时，反向梯度可能使参数离开区间。真实训练应观察近似 KL、clip fraction、优势分布、熵、value loss 和独立任务结果。

5. 策略奖励之外还要检查任务

算法提高的是定义好的期望回报。如果奖励遗漏了关键条件，PPO 可以稳定找到不符合预期却更高分的行为。机器人策略须检查实际轨迹、成功几何、接触和力信号，以及评估环境与部署观测的差异。

固定初态下训练的策略未必能容忍定位误差；仿真真值 Critic 有助于训练，但 Actor 必须使用部署可获得的观测。要报告实验覆盖和失败类型，不能从曲线收敛直接推断已经学会真机技能。

02 PPO 与 Actor–Critic

创建日期：2026-11-09
最近更新：2026-11-09

本章解决什么问题

策略梯度如何通过采样数据改进随机策略？Actor、Critic 和优势函数各自承担什么工作？PPO 的裁剪目标保护什么，又不保护什么？

本章整理策略优化原理；驱动器时间尺度与策略采样的关系分别见MIT 仿真和Rollout 专章。公式采用标准 on-policy PPO 约定；具体训练实现、动作和状态以项目配置为准。

快速回顾

  • Actor 表示策略 πθ(a∣s)；Critic 估计状态价值 Vϕ(s)，降低策略梯度估计的方差。
  • 优势 At 衡量当前动作结果相对于状态基准值的好坏，影响策略更新方向。
  • PPO 使用新旧策略的概率比率和剪切目标限制单批数据上的代理目标变化。
  • 裁剪不能保证真实策略 KL、环境回报或硬件安全一定受限；还需要观察实际训练和任务指标。

1. Actor–Critic 与策略梯度

随机 Actor 依据当前状态产生动作分布。环境按状态转移和奖励生成轨迹；Critic 学习期望折扣回报的基准值：

Vπ(st)=Eπ[∑k=0∞γkrt+k∣st].

原始轨迹回报波动很大。优势函数 Aπ(s,a)=Qπ(s,a)−Vπ(s) 减去状态基准，降低策略梯度估计方差，同时仍保留动作好坏的期望差异。

Generalized Advantage Estimation（GAE）常将 TD 残差按时间衰减求和：

δt=rt+γV(st+1)−V(st),A^t=∑l=0∞(γλ)lδt+l.

上述表达用于同一段未终止轨迹；实际有限 rollout 还需要终止／截断掩码，见 Rollout 专章。λ 控制偏差与方差权衡。截断 episode 时要按是否真实终止决定 bootstrap，时间限制截断不能无条件当成失败终止。

2. PPO 剪切目标

收集旧策略数据后，更新新策略。概率比率：

rt(θ)=πθ(at∣st)πθold(at∣st).

常见 clipped surrogate 最大化：

LCLIP(θ)=Et[min(rtA^t,clip(rt,1−ϵ,1+ϵ)A^t)].

正优势表示增加该动作概率通常有利；负优势表示减少它通常有利。剪切项防止目标鼓励概率比率沿有利方向无限增加，因此避免一次更新从代理目标中获得过大的收益。

剪切是训练目标的局部机制，不是严格的 KL 约束或信赖域保证。实践中常监控近似 KL、clip fraction、策略熵和总回报；某些训练器在 KL 太大时提前停止更新。

3. Critic 与训练目标

Critic 通过回归折扣回报目标来拟合 Vϕ(s)，常见多项目标包括 Actor 策略项、value loss 和熵奖励。共享 Actor/Critic 编码器时，value loss 与策略损失共同更新共享特征；分开参数时，梯度只走各自支路。须了解具体优化器的共享结构与梯度路由。

4. 非对称 Actor–Critic

在仿真训练中，Critic 可使用部署时无法获得的真实物体状态或接触标签作为特权信息，以改善价值估计；部署 Actor 只能使用真机可测输入。若把真值泄漏进 Actor 观测，所得结果无法直接部署。

Critic 输入包含 Actor 观测与真值特征，是一种训练信息设计，不代表奖励应由仿真自动变得正确，也不代表 Actor 已识别隐藏状态。应记录两侧输入、维度、归一化、历史拼接与部署对应关系。

5. 奖励设计与训练诊断

奖励引导行为，却不自动等同于任务成功定义。以末态误差做中间奖励时，策略可能卡在容易获分的临界状态；奖励权重需结合每项原始尺度、累计方式、成功判据、终止条件和独立验证。

以孔插入为例，如果奖励只鼓励最低点越过孔沿，带倾角浅插也可能获益。评估应同时报告几何真值、深度、倾角、接触力和成功状态，而不是只看奖励曲线与训练内成功率。

需检查 value loss、策略熵、动作分布、KL、裁剪比例、回合步数及随机种子。策略自动保存且回报稳定，并不代表任务达到预期；策略也可能钻成功判据的漏洞。无定位误差、理想力反馈下得到的仿真结果，不能宣称已经验证 Sim-to-Real。

03 奖励设计与模仿学习

创建日期：2026-11-09
最近更新：2026-11-09

本章解决什么问题

策略的真实任务目标与训练奖励如何对应？为什么额外惩罚有时会抑制所需行为？Teacher–Student、DAgger、RMA 和历史编码各解决哪种问题？

快速回顾

奖励应促进可验证的任务行为，不要让代理奖励取代真实成功定义。模仿学习用专家行为提供监督；DAgger 在 student 自己访问的状态上追加专家标签；历史编码和 RMA 则尝试从时间序列推断未显式观测的环境或动力学变化。

1. 奖励不是目标本身

奖励函数是优化对象的代理。设计时逐项明确原始量纲、正负方向、计算频率、门控条件、终止判据和每回合累计范围。奖励曲线提高只说明算法找到了高奖励行为，不自动说明任务成功。

在灵巧手抓取后旋转物体的任务中，可分阶段考察接近、建立稳定接触、实现目标旋转和维持抓取。若要求物体从不短暂失去任何接触，奖励可能阻断必要的 finger gaiting（手指交替释放并重建接触）。是否惩罚脱离，要结合任务是否需要重新换指判断。

排查奖励投机时，同时检查策略行为和独立物理事实：接触几何、穿透、位移、载荷、成功条件和异常终止。给奖励逐项作消融实验，通常比只看一个加权和更容易定位问题。

2. Teacher–Student 与 DAgger

Teacher–Student 训练让较强 teacher 基于仿真真值或特权状态产生动作，再教 student 从部署可得的传感输入学习。student 模仿得到的动作不一定满足安全限制，最终还须通过闭环评价。

行为克隆（Behavior Cloning，BC）将既有专家轨迹作为监督样本。但 student 一旦偏离专家轨迹，未来状态分布也可能偏离训练集，错误会逐步累积。

DAgger（Dataset Aggregation）迭代如下：

student 执行 → 收集 student 访问状态 → 专家标注这些状态
            → 追加数据集 → 重新训练 student

这样补充了 student 真正会遇到的分布，但依赖能够查询专家的标签、可靠安全采集和明确的数据混合规则。

3. RMA 与历史观测编码

Rapid Motor Adaptation（RMA）类架构使用一段短历史观测与动作，编码出当前任务状态没有直接提供的环境动力学特征，例如载荷、摩擦变化的代理表示。根据预测出的潜变量条件化控制策略，使其适应变化。

历史编码并不能保证潜变量等于某个真实物理参数；输入需包含对变化有信息的动态响应、时间戳和足够探索。若场景里执行器未激发负载差异，模型无法仅凭历史推断未观测量。

历史 encoder 可用重建或 teacher 特权量作为辅助监督，但要保持部署 Actor 的原始可观测边界。旧会话中的 RMA 配置示例属于讨论快照，不视为当前项目的实时实现。

4. 域随机化与课程学习

域随机化在仿真训练中对有现实依据的摩擦、质量、延迟、偏差和传感噪声等因素采样，扩大策略遇到的条件分布。随机化不是“越多越好”：范围过宽会增加与任务无关的难度，欠缺真实数据时任意范围也无法保证迁移。

课程学习逐渐调整初态或任务难度，以改善学习过程。课程定义应规定阶段指标、推进阈值、回退条件和各阶段独立评估；不能因为固定初态成功就假定带定位误差后也能成功。

04 Rollout、时间尺度与优势估计

创建日期：2026-11-09
最近更新：2026-11-09

本章解决什么问题

PPO 为什么采一小段就能更新？rollout、完整回合、物理步和“帧”是什么关系？TD、GAE 与训练 Critic 的 return 怎样连接？

快速回顾

Rollout 是当前策略采集的一段交互；不要求完整回合结束。Critic 为没有采到的后续收益提供价值估计。真正终止与人为截断必须区别处理；自动重置后的新状态不能冒充旧回合的末状态。

1. 从仿真子步到一批训练数据

层次 含义 拧盖项目历史讨论中的例子
内部子步 求解器在一个物理步内进一步积分 一个物理步可再细分，不能再次乘到配置的总物理时长上
物理步 仿真推进一次配置的时间间隔 曾使用 Δtp=1/240s
策略步 策略得到观测、给动作并与环境交互一次 当每步保持动作 24 个物理步时，为 0.1s
观测帧 某采样时刻的一份状态／图像 两帧历史关节观测不等于两张视频图像
渲染帧 显示或录像的一张画面 可以独立于策略频率和物理频率
Rollout 每个并行环境连续采集 H 个策略步 H=8 时，每个环境本批贡献 0.8s 交互
Episode 从任务开始到终止或回合截断 可能跨越很多批 rollout

这些数字是历史配置的说明，不代表当前全部训练设置。若每个策略步含 d 个物理步，策略周期为 Δtc=dΔtp。多环境共享一个联合动作策略时，一批 transition 数为：

B=NH.

N 为并行环境数，H 为 rollout 长度。双手联合动作不自动使样本数乘二；是否有独立 agent 维度，要看训练器的数据定义。历史例子中 8192×8=65536 条 transition；多轮更新复用的是这些数据，不是又采了同样多的新交互。

2. TD 误差：一次交互修正了多少价值判断

价值函数 V(st) 估计从当前状态开始的未来折扣回报。一步时序差分（Temporal Difference，TD）误差是：

δt=rt+γbtV(st+1)−V(st).

rt 为本步奖励，γ 为折扣因子；bt 决定下一状态能否提供 bootstrap，即用价值估计补上未来。真正终止时通常 bt=0；任务仍可继续但采样停止时通常 bt=1。有限时域任务若把期限本身定义为终止，则应按该任务定义处理，不能机械地给所有超时补值。

示例：V(st)=5、本步奖励为 1、V(st+1)=6、γ=0.9，非终止时 δt=1.4。这表示新的一步目标比原价值预测高，不是“动作的真实长期收益已经精确知道”。

3. GAE：把多步 TD 证据组合起来

广义优势估计（Generalized Advantage Estimation，GAE）可倒序计算：

A^t=δt+γλctA^t+1.

λ∈[0,1] 调节多步信息的权重。ct 表示优势递推是否继续连接同一回合；跨 episode 边界时为零，rollout 末端也结束本批递推。它与 bt 的作用不同：超时截断可以补上终态价值，同时切断与重置后新回合的优势连接。

较小 λ 更依赖局部价值预测；较大 λ 使用更长的奖励证据，通常降低对一步价值误差的依赖，但可能增加方差。不能把 λ 大解释成必然训练更好。

一种常见 Critic 目标为：

R^t=A^t+Vold(st).

这里必须用未经优势标准化的 A^t。训练 Actor 时可以另外标准化优势；把标准化后的优势加回价值会改变 Critic 目标。

4. 三种“结束”怎样区别

情形 下一价值 优势递推 易错点
任务真正终止，如失败吸收态 通常不补值 切断 不能跨到重置后的新任务
回合因外部时间上限截断，底层任务可继续 用截断前最终观测补值 切断 自动重置返回的观测可能已经属于新回合
只是 rollout 采满，环境未重置 用当前末状态补值 本批到此结束 不能把它当成任务失败

实现可能把超时补值提前加进奖励，再用统一的 done 掩码计算 GAE；也可能显式使用两个掩码。先读实现，避免同一次超时补值两次。本地 PPO 代码确有 terminal observation／超时补值路径；本章描述其需要满足的语义，不把所有库的字段名称当成相同约定。

5. 为什么短 rollout 能学长任务，又为什么仍要比较长度

Critic 把 rollout 之后的收益压缩成末端价值，因此采样窗口不必覆盖整个拧盖回合。代价是：若末端价值估计很差，较短窗口会更依赖它。换指、重新抓握和末段停转等延迟后果，可以成为比较更长 H 的理由。

增加 H 也增大批量、内存和采样等待时间，不能只改一个数就把收益归因于“看得更远”。比较时应记录总新交互量、B、更新次数、KL 和独立任务指标。工程中常见的 PPO 实现如 Spinning Up、rl_games 都采用“采样一批—优势／回报计算—若干轮小批更新”；参数最佳值由环境和执行预算决定。

05 观测噪声、域随机化与训练效率

创建日期：2026-11-09
最近更新：2026-11-09

本章解决什么问题

加噪声到底改变了什么？并行环境越多为什么不一定越快学会？持续增加域随机化后还有收益，是否说明没有收敛？

快速回顾

先区分“每秒采多少交互”和“学到目标性能需要多少交互”。观测噪声的单位、注入位置、重采样频率和相关性都是任务定义的一部分。训练分布一直变化时，不宜用一条总奖励曲线判断固定问题的收敛。

1. 噪声必须说明位置、单位和时间结构

若原始关节角观测为：

q~t=qt+ϵt,ϵt~N(0,σq2I),

则 σq 以 rad 为单位。先归一化再加相同数字的噪声，含义不同。例如归一化 z=2(q−qmin)/(qmax−qmin)−1 后，原始角度噪声对应：

σz=2σqqmax−qmin.

历史会话核对过某配置的 σq=0.4rad，约为 22.9∘，属于很大的角度噪声；不能误读为归一化空间中的小扰动。该历史实现按策略步给独立手关节位置采样，不等于给所有机器人关节、每个物理子步都加噪声。本章不把它当成当前配置或实机测量精度。

随机因素 典型时间结构 对策略的影响
白噪声式测量扰动 每次观测重采样 历史滤波可减少部分独立噪声
编码器零偏／相机外参误差 一个回合或较长时段固定 不能靠多帧简单平均消除
通信延迟 固定或随时间变化 观测来自过去，需要处理动作与观测时间对齐
质量、摩擦、执行器参数 常在回合重置时采样并保持 改变动力学，历史交互有助于推断隐含参数

独立重采样是建模选择，不是“高斯分布”自动包含的性质。把真实慢变偏置全写成独立白噪声，可能训练出能平均噪声却应对不了系统偏差的策略。

2. 为什么用历史观测，什么时候需要 RMA

单帧相同的关节位置，可能对应不同速度、接触或负载状态。历史观测／动作能提供变化趋势，从而缓解部分可观测性。两帧历史不是所有隐藏状态的充分统计量，也不能恢复从未测到的信息。

历史堆叠实现简单；循环网络可学习更长时序表示，但要正确管理隐藏状态与回合重置。RMA 则显式学习从近期状态—动作历史预测影响控制的潜变量，并与基策略配合。RMA 原论文验证的是四足机器人适应，不能据此断言在双手拧盖上一定优于简单历史堆叠。见奖励设计与模仿学习。

项目上优先比较“测得的噪声／延迟范围内，当前历史是否已满足稳定操作”，再决定是否增加网络复杂度。增加历史长度本身也会改变输入维数、内存和训练难度。

3. “跑得慢”与“学得慢”怎样拆开

总耗时可按实际计时拆为：

T=Tphysics+Tinference+Ttransfer+Tupdate+Tevaluation.

仿真与 GPU 操作可能异步重叠，不能直接把未经同步的计时器数字相加。先使用一致的计时口径，再区分吞吐瓶颈与学习瓶颈。

  • 若仿真／采样占主要时间，优先查接触复杂度、物理步数、CPU—GPU 同步和不必要的数据回传；换更大的网络通常没有针对性。
  • 若任务指标随交互增长很慢，优先查奖励、探索、可观测性、课程跨度和更新质量；更高 GPU 利用率不等于更有效学习。
  • 若评价成本很高，区分训练采样和独立评价的时间；不能把频繁评价开销误判成 PPO 更新慢。

历史拧盖会话曾观察到采样显著比网络更新耗时，应作为“先测量再优化”的案例，不能把当时比例推广到所有训练。

4. 并行环境数与长回合覆盖的关系

在总交互预算 S 下，若分配均匀，每个环境平均推进：

L=SN,tper env=SNΔtc.

示例：S=107、N=8192、Δtc=0.1s 时，每个环境约推进 122s；翻倍 N 而不增加总预算，则约为 61s。这是无提前重置时的量级估算；真实回合覆盖还受随机重置和起始状态分布影响。

如果每次课程换档都重置环境，且任务关键失败在回合末段，固定小预算加大量并行环境可能缺少末段覆盖。但若同档训练持续、状态跨更新保留，就不能说每次短 rollout 都只能见到开头。

多瓶型共享策略时，不是每个瓶型都独立训练一套网络。每类环境数量影响覆盖和梯度分布，但共享结构也能迁移经验。可以用逐瓶评价和困难样本重采样改善短板，同时保留其他样本覆盖以防遗忘。

5. 怎样做有信息量的对比

固定目标域随机化（Domain Randomization，DR）分布和评价任务，再比较少量候选 N、H 或课程跨度。记录达到同一成功率所需墙钟时间和新交互量，同时检查掉落率、末段转速、困难瓶表现和多个随机种子下的波动。

总交互量、每轮批量、总更新量与墙钟时间不能在所有实验中同时保持不变；应说明此次主要比较哪一种效率，并报告随之变化的量。不要一次改环境数、奖励、噪声与学习率，再把结果归因于单个因素。

工程中常用并行仿真提高采样吞吐；PPO 的开源实现也暴露这些批量参数。但“把显存填满”不是通用选择规则，环境数需要通过吞吐和任务覆盖共同选择。

6. DR 一直变化时如何判断停止

持续提高噪声、摩擦或负载范围，相当于持续改变优化问题。此时性能还有收益，不等于在固定分布上永远不收敛，也不能凭累计训练很久判断该停止。

更有意义的终点是：由目标部署条件确定需要覆盖的范围，在该范围固定后，以独立评价检查是否满足成功率和失败边界。DR 过宽会增加学习成本；过窄又可能漏掉真实扰动。仿真内达到指标仍需经过对应实机条件的验证。

06 强化学习与在线优化的选择

创建日期：2026-11-09
最近更新：2026-11-09

本章解决什么问题

“RL 不可能比设计得好的在线全局优化更好”成立吗？双手拧盖与机械臂接触任务中，应该在哪些层使用学习或优化？

快速回顾

相同真实模型、相同信息、相同目标和可行集合下，真正的全局最优当然不可超越。实际比较的是有限模型、有限预测时域和实时预算下的控制器，与经历大量离线训练的策略；两者承担的计算成本和误差来源不同。

1. 先把“最优”的前提写清楚

有限预测时域的模型预测控制（Model Predictive Control，MPC）可写为：

minu0:H−1∑k=0H−1ℓ(xk,uk)+Vf(xH),xk+1=f(xk,uk),(xk,uk)∈C.

实际执行第一步，获取新状态后重新求解。即使每次把这个有限时域问题全局求解，也不自动等于真实无限时域任务的最优策略：模型 f、终端价值 Vf、预测长度和状态估计都可能近似。

RL 则通常把大量交互与优化放在离线训练，部署时调用 u=πθ(o)。它不天然全局最优；奖励代理、训练分布和函数逼近也会引入偏差。历史会话提出了这一比较问题，本节是本轮补充的条件分析，不声称此前已完成了全部论证。

2. 按工程约束比较

维度 在线优化／MPC RL 策略
在线计算 要求解问题，依赖维数、接触结构和求解时限 通常为一次网络推理，低延迟但仍要测最坏耗时
模型与数据 通常显式建模，模型误差会进入预测 可从数据学到复杂响应，但需要采样并处理分布变化
约束 可以显式建模；仍受模型、可行性和容差影响 普通奖励惩罚不保证硬约束满足
长时接触与换指 接触模式组合和长时域可能求解困难 可学反馈行为，但探索和奖励设计困难
改变目标 在已有模型与约束内常能直接重设目标 要看目标是否作为输入、训练是否覆盖；可能需重训
诊断 可看约束残差、模型与求解日志 可看行为与分布；内部表示的解释通常更困难

这是一组常见取舍，不是全行业方法排名。模型预测控制也可以学习模型／终端价值；RL 也可以在部署时调用优化器，二者并不互斥。

3. 联系双手拧盖项目，为什么选择学习接触行为

拧盖涉及多指接触切换、摩擦、双手配合和反复换指。若每个控制周期都联合优化长时接触序列，建模和求解负担可能很重。在仿真中训练 PPO，再部署反馈策略，是把这些搜索成本移到训练阶段的一种路线；是否值得，取决于任务复用次数、仿真可信度和可用训练资源。

项目中仍应保留可验证的关节映射、驱动接口、限幅、时间戳和任务评价。策略给出动作，并不意味着电流环、通信和约束处理也应交给同一个网络学习。对比基线可从可行的规则控制／轨迹加反馈开始，衡量成功率、掉落、末段转速与部署扰动下的表现，而不是只比较训练奖励。

4. 联系七轴臂和插接，什么时候优先优化与模型控制

已知目标位姿、清楚的关节限位和较可靠几何模型，适合先用数值 IK、路径规划与反馈控制完成自由空间运动。局部插接若有可用力反馈和明确接触方向，可以先建立阻抗／导纳或混合力位控制基线，再看残余误差是否值得学习。

若希望策略与优化互补，可让学习模块预测残差、接触阶段或候选动作，再由受限优化／控制层执行。若使用动作投影，必须说明投影依赖的状态估计和约束模型；优化器的成功标志本身不证明真实系统安全。

本段属于结合项目的选型建议，未宣称已经在你的插接项目中做过 RL 与 MPC 的实机性能对比。

01 MIT 模式与电流模式

创建日期：2026-11-07
最近更新：2026-11-07

本章解决什么问题

电机驱动器的 MIT 模式与电流模式有什么区别？它们怎样影响位置、速度和输出力矩？

本章采用机器人关节中常见的永磁同步电机（PMSM）及磁场定向控制（FOC）背景，解释常见的 MIT 风格接口。MIT 模式并不是所有厂家统一实现的标准，具体产品的协议和控制实现需要查阅其手册。本次讨论尚未指定实际设备。

快速回顾

  • 电流模式：上位机给出目标电流，驱动器通过电流闭环跟踪。在常见的 q 轴电流控制条件下，电流近似决定电磁力矩；位置和速度怎样变化，还取决于负载和外部控制器。
  • MIT 模式：上位机通常给出目标位置、目标速度、位置增益、速度增益和前馈力矩。驱动器根据位置与速度误差计算目标力矩，再通过底层电流控制执行。
  • 两者的主要区别是对上位机开放的命令层级，以及位置、速度反馈控制由哪里计算。MIT 模式底层通常同样依赖电流环。
  • 常见 MIT 控制律可以理解为在底层电流控制之上加入关节刚度、阻尼反馈，形成一种关节阻抗控制；它不会自动实现任意期望惯量或末端笛卡尔阻抗。
  • MIT 模式中令位置、速度增益都为零，常见控制律便退化为前馈力矩控制。若力矩与电流换算一致，它与电流模式可以实现近似相同的输出。

1. 电流模式：直接指定目标电流

典型控制关系为：

上位机的目标电流 → 驱动器电流环 → 电机电磁力矩 → 机械运动

在常见的表贴式 PMSM、d 轴电流近似为零、未进入明显饱和等条件下，可以使用近似关系：

τm≈Ktiq
符号 含义 单位
τm 电机轴的电磁力矩 N·m
iq q 轴电流，常用作产转矩电流 A
Kt 与所采用电流定义相匹配的力矩常数 N·m/A

直觉上，上位机在决定“施加多大的力矩”。例如，在本节假设成立且 Kt=0.1 N·m/A 时，目标 iq=2 A 对应约 0.2 N·m 的电机电磁力矩。这是说明性示例，并非用户设备参数。

这并不意味着电机会自动停在某个位置。相同电流下，电机可能加速、被外力拖动，或与负载达到平衡。若希望跟踪位置，上位机可以自行根据位置、速度反馈计算力矩，再换算为电流命令。

还需区分：电流闭环通常能直接控制电磁力矩的主要来源，但实际轴端力矩还受摩擦、传动和其他因素影响；这不自动等于带力矩传感器的轴端力矩闭环。

2. MIT 模式：驱动器按反馈误差计算力矩

常见 MIT 风格接口包含五个主要命令字段：

字段 含义 常见单位
qd 目标位置 rad
q˙d 目标速度 rad/s
Kp 位置反馈增益，可理解为虚拟刚度 N·m/rad
Kd 速度反馈增益，可理解为虚拟阻尼 N·m·s/rad
τff 前馈力矩 N·m

这些单位建立在各个量使用一致的机械轴坐标和物理单位的前提下，不能直接套用于采用归一化增益或其他单位的产品。

驱动器读取实际位置 q 与实际速度 q˙，计算：

τcmd=Kp(qd−q)+Kd(q˙d−q˙)+τff

这里 τcmd 是控制器要求的力矩，实际执行还会受到电流、速度、电压和温度等限制。

三项分别表示：

  • 位置项：位置偏离目标时产生恢复力矩，类似虚拟弹簧。
  • 速度项：速度偏离目标时产生纠正力矩。当目标速度为零且增益为正时，它表现为阻碍运动的虚拟阻尼。
  • 前馈项：不依赖当前误差，直接叠加所需力矩，例如由模型计算的重力补偿。

典型控制关系为：

上位机的五个命令字段 → 驱动器的 PD＋前馈力矩计算 → 力矩换算为目标电流 → 电流环 → 电机

这一形式常称为关节阻抗控制，也常被厂家称为混合控制。它是在力矩命令中同时使用位置和速度误差反馈，并不意味着位置、速度和力矩三个物理量可以被任意独立地精确指定。

与阻抗控制的关系

用户的理解“MIT 模式可以理解成加入了阻抗控制”对上述常见实现是成立的。更准确地说：在底层电流／力矩执行之上，加入了基于位置和速度反馈的虚拟弹簧、阻尼关系。

阻抗控制关注运动与作用力之间的动态关系。对于关节，运动量是转角，作用量是力矩。目标不是无论外力多大都保持同一位置，而是让关节以设定的刚度和阻尼响应偏移与运动。

以固定目标位置、目标速度为零为例：

  • Kp 决定虚拟弹簧的刚度。相同位置偏差下，Kp 越大，恢复力矩越大。
  • Kd 决定虚拟阻尼。相同实际速度下，Kd 越大，反向的阻尼力矩越大；它作用于运动过程，不会在静止时额外提供位置恢复力矩。
  • τff 可提供重力补偿等基准力矩。

在单关节、静态、无饱和，且其他负载已被前馈准确补偿的理想条件下，若 Kp>0，额外外力矩 τext 与位置偏移满足：

Kp(qd−q)+τext=0⇒q−qd=τextKp

这里外力矩与关节转角使用同一正方向。因此，同样的额外外力矩作用下，刚度越小，静态偏移越大；阻尼项在静止时为零。该关系说明刚度的含义，不保证实际设备在任意增益下都稳定。

需要保留两个边界：

  • 上述 PD 形式直接设置虚拟刚度和阻尼，关节的物理惯量仍然存在；它不自动实现任意指定的虚拟惯量，也不自动包含机械臂末端的笛卡尔阻抗控制。
  • 电流模式同样可以实现阻抗控制：上位机根据反馈计算弹簧、阻尼力矩，再换算成电流。MIT 模式常把这部分计算放到驱动器中。

3. 一个计算例子

以下全部为示例，假设位置、速度与力矩都定义在同一轴端：

qd=1.0 rad,q=0.8 rad
q˙d=0,q˙=0.5 rad/s
Kp=10 N·m/rad,Kd=1 N·m·s/rad,τff=0.3 N·m

此时：

τcmd=10(1.0−0.8)+1(0−0.5)+0.3=1.8 N·m

位置项产生 2.0 N·m 的恢复力矩；速度项产生 −0.5 N·m 的阻尼力矩；前馈再加上 0.3 N·m。

使用电流模式时，上位机也可以计算同样的式子，再根据轴端约定和力矩常数换算成目标电流。因此，两种模式可以实现相似的控制律，差别在于计算位置、执行频率和通信依赖等工程条件。

4. 两种模式的对应关系

比较项 电流模式 常见 MIT 模式
上位机主要发送 目标电流 目标位置、目标速度、两个增益、前馈力矩
驱动器的主要任务 跟踪电流命令 计算 PD＋前馈力矩，再用电流控制执行
位置、速度反馈控制 如需要，由上位机或其他外环实现 常见实现由驱动器本地执行
本身是否指定保持位置 单独给定电流不会建立位置恢复规律 正的位置增益会建立位置恢复力矩

本地控制并不保证性能一定更好。实际结果还取决于采样频率、滤波、参数、通信延迟和设备实现。

5. 特殊参数与易错点

两个增益都为零

Kp=Kd=0⇒τcmd=τff

在上述控制律下，目标位置和目标速度不再贡献力矩，模式退化为前馈力矩控制。需要结合产品手册确认是否另有摩擦补偿、保护或其他控制逻辑。

只保留速度项

当 Kp=0、Kd>0、q˙d=0、τff=0 时：

τcmd=−Kdq˙

此时表现为阻尼，不会主动把关节拉回某个角度。若目标速度非零，比例速度反馈本身也不保证有负载时的零稳态速度误差。

设了目标位置，不代表一定准确到位

目标位置是否起作用取决于 Kp。即使 Kp>0，常见 PD 控制也可能需要非零位置误差来平衡外部负载；正确的前馈补偿能减少这类误差。实际输出还可能受限幅影响。

力矩、电流和减速器轴端不能混用

  • 电流模式的“电流”可能指 q 轴电流、相电流的某种幅值等，应确认定义；母线电流不能直接代入本章的 q 轴力矩公式。
  • 力矩常数所用的峰值或有效值约定必须与命令电流一致。
  • 有减速器时，确认命令位置、速度、增益和力矩是电机侧还是关节输出侧。所有项必须使用相匹配的坐标。
  • 若减速比定义为 N=ωm/ωout，在简单的准静态正向传动近似下，输出力矩可估算为 τout≈ηNτm，其中 η 为效率。反向驱动、动态运动和摩擦可能需要不同模型。

02 MIT 驱动器的仿真建模

创建日期：2026-11-07
最近更新：2026-11-09

本章解决什么问题

在物理仿真环境中，怎样模拟常见 MIT 模式驱动器，需要设置哪些参数？

前置知识：MIT 模式与电流模式。本章采用转动关节、关节输出侧坐标，未指定具体仿真器与真实驱动器。文中的控制接口为概念接口，不是某个仿真器可直接运行的 API。

快速回顾

常用的第一版模型是：机械关节模型＋MIT 控制律＋力矩限幅＋明确的执行周期。由仿真器计算机械运动，由自定义驱动器模型根据关节反馈计算施加力矩。

底层电流环可以先近似为理想力矩源；需要提高驱动器动态或仿真到实物的一致性时，再增加带宽、延迟、摩擦、转子惯量和速度相关力矩限制等特性。模拟 MIT 的机械行为不要求一开始就模拟 PWM、逆变器或完整 FOC。

1. 第一版需要明确的设置

设置 需要决定什么 常用的初始做法
机械模型 连杆质量、质心、惯量、关节轴、重力、机械限位，以及任务需要的接触 使用经过检查的机器人模型
执行接口 力矩是否直接作用到目标关节，接口是否有缩放或传动映射 使用已确认映射关系的关节力矩／effort 接口
坐标和单位 零位、正方向、rad、rad/s、N·m，以及电机侧／关节侧 第一版统一在关节输出侧计算
MIT 参数 qd,q˙d,Kp,Kd,τff 每个关节分别配置，允许随命令更新
输出能力 允许输出的正、负力矩 对最终合成力矩限幅
时间设置 物理步长、驱动控制周期、上位机命令周期 分别定义，避免隐含为同一个频率

关节运动由机械动力学决定。MIT 驱动器模型负责生成力矩，不应再额外直接修改关节位置来模拟跟踪效果。

2. 核心计算与力矩接口

在驱动控制时刻读取 q 和 q˙，计算：

τraw=Kp(qd−q)+Kd(q˙d−q˙)+τff

然后对总力矩限幅：

τcmd=clip(τraw,τmin,τmax)

这里 τmin、τmax 为允许的负向与正向输出力矩，第一版可以取对称常数。仿真器执行的关节力矩应与这些量使用一致的坐标。

如果采用外部显式计算的这条路径，要关闭会额外叠加力矩的内置位置／速度伺服。否则可能同时存在自定义 PD 和内置 PD，使实际刚度、阻尼与设定不一致。被动力学中的真实摩擦、阻尼可以保留，但应明确它们与控制器阻尼的区别，避免重复建模。

也可以使用仿真器内置的关节驱动：前提是其控制律、增益单位、目标速度、前馈叠加、限幅和离散实现符合需要。隐式位置驱动与外部离散 PD 即使填写相同增益，数值行为也未必一致，不能仅凭参数同名就认定等价。

坐标约定的检查

  • 模型的目标位置、反馈位置必须使用一致的零位和方向。
  • 第一版若直接给关节输出力矩，就不要再无依据地乘一次减速比；检查接口是否已包含传动映射。
  • 仅当显式建立电机侧模型时，再进行电机电流、力矩常数与减速器的换算。
  • 连续转动关节的角度误差需明确采用多圈角度还是最短角距离；有机械限位的关节不能随意把误差包装到 [−π,π)。

3. 三种时间尺度：命令、驱动控制和物理仿真

三者含义不同：

  • 上位机命令周期：多久更新五个命令字段。例如轨迹规划器或策略多久发送一次新目标。
  • 驱动控制周期：多久使用最新本地反馈重新计算 MIT 力矩。
  • 物理步长：物理引擎多久推进一次动力学状态。

以下仅为说明性时间设置，不代表用户设备参数或通用推荐值：

  • 上位机每 20 ms 更新命令，即 50 Hz。
  • 驱动控制周期与物理步长均取 1 ms，即 1000 Hz。

在一次上位机命令间隔内，五个字段保持不变，但驱动器会计算 20 次力矩；每次都使用当前反馈。保持目标不等于保持力矩，因为运动过程中位置、速度误差持续变化。

如果驱动控制周期大于物理步长，通常在两次驱动更新间保持其输出力矩，并按物理引擎 API 的要求持续施加。若要模拟更快的驱动控制，需要合适的物理子步或等效模型，不能在没有推进机械状态时简单重复调用控制器来获得同等效果。

概念伪代码

下面对应驱动控制周期等于物理步长的情形：

for each_physics_step:
    if a_new_high_level_command_arrives:
        # 更新后保持这些字段，直到下一条命令到来。
        q_des, dq_des, kp, kd, tau_ff = receive_command()

    q, dq = read_local_joint_state()
    tau_raw = kp * (q_des - q) + kd * (dq_des - dq) + tau_ff
    tau_cmd = clip(tau_raw, tau_min, tau_max)
    apply_joint_effort(tau_cmd)  # 接口缩放和传动映射已确认
    step_physics()

命令接收应在控制开始前初始化；该代码省略了设备特定的启停、超时等状态逻辑。

4. 刚度和阻尼怎样起步

Kp、Kd 应按关节配置，不能只因为都叫 MIT 模式就采用统一固定值。实际效果取决于负载惯量、控制周期、延迟、接触状态和力矩上限。

对于固定目标、忽略其他因素的简化单关节：

Jq¨+Kdq˙+Kp(q−qd)=0

其中 J 为该关节坐标下的等效惯量，单位为 kg·m2。在该简化模型下：

ωn=KpJ,ζ=Kd2JKp

因此可用下式获得阻尼的初始估计：

Kd=2ζJKp

这里 ωn 为自然角频率，ζ 为无量纲阻尼比；Kp 单位为 N·m/rad，Kd 单位为 N·m·s/rad。若机械模型中已有粘性阻尼，方程中的总阻尼还包含该部分。

这只是忽略耦合、延迟、离散采样和饱和时的初始估计。机械臂的有效惯量会随姿态变化，不能仅以电机转子惯量代替全部负载；连续模型中的临界阻尼也不保证离散仿真始终稳定。应通过实际响应检查并调整增益与步长。

5. 更接近真实驱动器时增加什么

特性 要设置的量 它影响什么
力矩／电流响应带宽 响应时间常数或辨识得到的动态模型 真实输出不能瞬间追上目标
通信与计算延迟 命令延迟、反馈延迟、抖动 跟踪与闭环稳定性
输出能力随工况变化 力矩—转速包络、供电约束、峰值与连续能力 高速与持续负载下的可用输出
传动与电机机械特性 转子惯量、摩擦、效率，必要时背隙与弹性 加速、回驱与接触响应
反馈特性 编码器分辨率、速度滤波、噪声 小幅运动和阻尼项的实际行为
协议与运行状态 字段范围、量化、使能、失联处理 与真实命令接口及异常状态的一致性

这些特性应根据任务和真实设备逐步加入，而不是任意堆叠。局部驱动反馈与上位机观测可能是不同通路，不能把上位机观测延迟直接当作驱动器内部反馈延迟。

例如，可用一阶模型近似力矩响应：

τ˙act=τcmd−τactTτ

在一个步长 Δt 内命令保持恒定时，可更新为：

τact,k+1=τact,k+(1−e−Δt/Tτ)(τcmd,k−τact,k)

Tτ>0 为响应时间常数，单位为秒；此时施加的是 τact，而不是理想命令 τcmd。这是执行器动态的简化近似，不是完整电气模型，具体更新时序与限幅位置应和所选仿真模型保持一致。

若显式考虑减速器和转子惯量，理想刚性传动下转子折算到关节侧的惯量为 Jref=N2Jm，其中 N=ωm/ωjoint。需检查仿真器的转子惯量／armature／传动模型是否已计入，避免重复添加。

6. 怎样检查模型是否符合预期

  1. 零增益检查：Kp=Kd=0 时，输出应由前馈力矩及执行器限制决定。
  2. 纯阻尼检查：Kp=0、目标速度为零、无前馈时，输出力矩应反向于速度；不应存在位置恢复项。
  3. 静态外力检查：在其他力矩已补偿且未饱和时，额外外力矩导致的偏移应近似满足 q−qd=τext/Kp。
  4. 阶跃与饱和检查：观察位置、速度、限幅前后力矩；确认输出不超过定义的能力，并检查振荡。
  5. 时间尺度检查：保持上位机目标不变时，运动中的反馈力矩仍应随驱动控制周期更新。

这些是建模后的建议验证方法，本次仅整理理论与建模步骤，尚未运行仿真实验。

03 PMSM 与 FOC

创建日期：2026-11-09
最近更新：2026-11-09

本章解决什么问题

永磁同步电机（PMSM）的三相电流如何参与产生转矩？磁场定向控制（Field-Oriented Control，FOC）为什么需要 Clarke 与 Park 变换？

快速回顾

FOC 根据转子电角度把三相电流映射到旋转的 d/q 坐标系，以近似独立调节磁链相关分量和转矩相关分量。q 轴电流和电机电磁力矩相关；它不是关节输出力矩传感器，也不说明驱动器的电流定义或轴侧换算。

1. 主要控制链

典型电流 FOC 闭环如下：

采样相电流 ia、ib、ic 与电角度 theta_e
    -> Clarke：静止坐标系 i_alpha、i_beta
    -> Park：旋转坐标系 i_d、i_q
    -> d/q 电流 PI 与电压／电流限制
    -> 逆 Park 与 SVPWM 生成逆变器开关信号
    -> PMSM 与电流采样反馈

实际实现可能使用两电流采样、不同 PWM 调制、采样补偿、反电势前馈或电流解耦；上图只是基本概念链。

2. 坐标变换的意义

Clarke 变换把三相量映射到静止两轴平面；平衡三相且无零序分量时，两维足以表示平面磁场。Park 变换再绕转子磁链同步旋转，使随电角度变化的交流分量在稳态时近似为直流量，PI 控制器更易处理。

工程公式需明确 Clarke 的幅值不变还是功率不变归一化，d/q 轴方向，电角与机械角的关系，以及电流峰值还是 RMS。不同约定会改变换算系数，不能只复制一种符号表。

3. 电流与电磁转矩

表贴式永磁同步电机、采用常见峰值相电流与相应 Park 约定时，电磁转矩简化为：

τe≈32pψfiq.

p 是极对数，ψf 是永磁磁链，iq 是 q 轴电流。符号和常数因坐标与电流归一化而异。凸极内嵌式 PMSM 还含 id 和 d/q 电感差产生的磁阻转矩项。

因此常见 τe≈Ktiq 是已吸收到所选约定中的工程写法。电机电磁转矩经过转子惯量、轴承、减速器、效率和摩擦后，才与关节输出转矩相关。

4. PI 与 SVPWM

d/q 轴电流控制器比较实测电流和目标电流，PI 产生电压命令。电机绕组电感和电阻决定电流响应；电压受直流母线和调制饱和限制，目标电流可能无法达到。SVPWM（Space Vector Pulse Width Modulation）依据所需电压矢量选择逆变器开关占空比，受母线电压与扇区线性范围约束。

电流模式仍是反馈控制，只是闭环主要控制 q 轴／电流。上层若需要位置或速度跟踪，还需另加外环或使用驱动器提供的更高层模式。

04 PID、重力补偿与计算力矩

创建日期：2026-11-09
最近更新：2026-11-09

本章解决什么问题

位置误差反馈、重力前馈和完整动力学前馈分别补偿什么？为什么提高位置增益不总能改善接触或跟踪？

快速回顾

PID／PD 根据测得的误差修正输出；重力补偿依据构型提供前馈；计算力矩进一步使用惯性和速度耦合模型。三者都受传感、模型、延迟和执行器限幅影响，不能用一个名词概括“闭环精度”。

1. PD 与 PID

以关节位置误差 e=qd−q 表示，一种常用形式是：

τfb=Kpe+Kd(q˙d−q˙)+Ki∫edt.

Kp 提供位置恢复作用，Kd 提供速度误差阻尼，积分项处理持续偏差。若采用误差导数形式 e˙，其符号、目标速度定义必须保持一致。离散实现中需考虑微分噪声、积分饱和、采样周期和抗饱和策略。

增大 Kp 可能提高局部刚度，也会放大观测误差和接触冲击、促使输出饱和；Kd 使用噪声很大的速度反馈可能诱发力矩抖动。增益稳定范围需结合闭环周期和机构验证。

2. 重力前馈

常见关节 PD 加重力补偿：

τ=g(q)+Kpe+Kd(q˙d−q˙).

模型方向和求解器约定一致时，前馈补偿机器人的静态重力项，反馈负责剩余误差。前馈不是额外的位置闭环，也不会自动消除摩擦、外部接触和传动误差。

如果重力模型含未分离的偏置项，应如实标识，不要把拟合偏置说成已经独立确认的物理重力来源。详细边界见重力与摩擦辨识。

3. 计算力矩控制

以动力学 Mq¨+Cq˙+g=τ 为例，定义期望加速度：

ad=q¨d+Kd(q˙d−q˙)+Kp(qd−q).

理想逆动力学命令：

τ=M(q)ad+C(q,q˙)q˙+g(q).

代入精确模型且忽略摩擦、饱和和接触时，得到近似线性误差响应。实际模型误差、时延、外力和设备保护会造成偏差，所以此公式是控制结构，不是稳定性或实机性能保证。

4. 控制层级

更快的内层电流闭环通常调节电磁转矩相关电流，关节伺服／计算力矩在其上产生需求。命令通过减速器时要确认每一层是否已经包含传动比、方向、效率和限幅，不能将同一补偿叠加两次。

如果需要控制接触时的柔顺响应，应先明确正在使用的电流、位置或力矩接口，及力传感器／估算器的带宽。阻抗与导纳详见下一章。

5. 项目中的纯重力补偿，为什么不等于位置保持

历史七轴臂讨论中，重力补偿会话不含位置弹簧或速度阻尼；本轮查看 SDK 的 GravityCompensationSession 仍显示其没有参考输入和 PD 项，update() 是心跳。其理想补偿结构是：

τmodel=g^(qmeas)+b0.

实际发送还要经过设备约定下的限幅等处理。虽然 qmeas 来自反馈，模型也随实测姿态更新，但控制律没有比较 qd−q，所以不能把它说成能恢复到给定姿态的位置闭环。电流内环可以闭环，也不意味着外层已经闭环调节真实关节力矩。

对真实动力学：

M(q)q¨+C(q,q˙)q˙+g(q)+τf=τ+τext,

即使 g^=g 且无偏置，外力、初速度和摩擦仍然决定运动；没有弹簧项把偏离拉回，没有阻尼项主动消耗运动。仿真或某次姿态下能停住，可能依赖静摩擦，不是“所有姿态位置稳定”的证明。

6. 为什么不立即换成完整计算力矩

目标／条件 可以优先考虑 为什么
研究近似重力平衡、允许人手引导 已验证范围内的重力补偿 控制结构简单，便于观察模型残差；不能当位置保持器
跟踪关节参考姿态／轨迹 重力前馈加 PD，并处理饱和 用反馈处理模型残差，同时明确参考和速度质量
快速轨迹、耦合显著且模型和执行带宽可靠 逆动力学／计算力矩 补偿惯性与速度耦合，但对模型、加速度目标和时序要求更高
接触任务、希望可控柔顺 合适接口上的阻抗／导纳 把接触响应作为设计目标，而不是单纯加大位置增益

标准机器人教材与库中，上述结构都很常见；“完整动力学项最多”并不意味着对当前硬件最合适。当前项目仍需区分协议力矩标度、可用反馈和模型精度，先提高这些环节的可信度，通常比立刻叠加更多补偿项更有信息量。这里是选型分析，未替你改变实机控制律。

本轮查看的 TorqueControlSession 还明确把调用方输入定义为重力之外的额外力矩，SDK 在内部叠加重力前馈；不能把另一个厂商“直接力矩接口”的示例照搬后再次加重力。是否自动补偿，应逐接口核对，不能凭模式名称推断。

7. 验证控制效果应看什么

关节跟踪可比较位置／速度误差与饱和占比；重力补偿可检查多姿态漂移和外力下响应；接触控制还要看接触力、过冲和通信延迟。使用电流估算的“力矩反馈”时，应标明其测量来源，避免把同一个比例系数的回读自洽当成独立力矩验证。详见电流—力矩辨识。

对反馈噪声引入滤波时，要同时检查延迟；仅把曲线变平滑不足以证明闭环变好，见EMA 滤波。

05 阻抗、导纳与力位混合控制

创建日期：2026-11-09
最近更新：2026-11-11

本章解决什么问题

接触任务为什么需要柔顺性？阻抗、导纳和笛卡尔力控分别控制什么？上层策略输出位姿增量时，下面怎样实现，位置精度又应该怎样评价？进一步讨论关节与笛卡尔阻抗的选择、倾斜表面及边角接触，以及迁移到真机时的失效原因。

本轮明确的项目条件：任务需要与物体接触，上层策略输出末端位姿增量，下面的控制器可以修改。尚未确认具体机械臂、增量坐标及累积规则、力传感通路、控制频率和接触几何。因此以下是可选架构和条件性分析，不是已经部署或验证的控制方案；所有数值均为说明性示例。

快速回顾

  • 阻抗（Impedance）和导纳（Admittance）描述力与运动之间的动态关系；笛卡尔力控（Cartesian Force Control）描述在末端任务空间控制力的目标，它们不是三个互斥档位。
  • 典型力矩型阻抗由运动误差生成力／力矩指令；典型导纳由外力或力误差生成运动指令，下面可以采用位置伺服。输出力矩不等于闭环跟踪指定接触力。
  • 柔顺不意味着自由空间必然到不了点。有限刚度下的受力偏移、补偿误差、静摩擦、动态滞后和运动学限制，需要分别诊断。
  • 导纳的位置内环可以很准确，但准确跟踪的是修正后的参考；不能因此说它比阻抗更忠实于策略原始轨迹。
  • 接触方向由几何约束定义，可以倾斜于世界坐标轴。各向异性阻抗不等于显式力位混合，多面接触也不能只按 XYZ 独立调参。
  • 低刚度不能消除所有冲击；接近速度、有效惯量、机械弹性、采样和执行延迟同样关键。

1. 从机械运动到控制接口：先分清三层

1.1 力矩产生运动，但力矩命令不是接触力测量

以固定基座机械臂为例，关节动力学可写成：

M(q)q¨+C(q,q˙)q˙+g(q)+τf=τact+JTwext.

q 是关节位置，M 是惯性矩阵，Cq˙ 表示科氏／离心项，g 是重力项，τf 是放在左侧的摩擦项；τact 是实际执行器广义力矩，wext 是环境作用在末端的外力旋量。坐标、参考点及符号须与 J 匹配。

电机电流、关节力矩和接触力不在同一层。力矩指令还要经过电流环、传动与机械动力学，才能形成实际运动和接触力；执行器饱和、摩擦和模型误差都会改变结果。完整动力学背景见动力学方程。

1.2 策略输入、控制器算法、底层执行不能混为一谈

层级 本项目中的含义 容易混淆的地方
上层任务／策略 输出末端位姿增量 不决定下面一定是位控还是力矩控制
控制算法 阻抗、导纳、位置伺服或显式接触力闭环 需要根据任务目标和反馈能力选择
执行接口 关节位置、速度、力矩／电流等 接口允许发送力矩，不代表实际接触力已闭环

“导纳本质是位控、阻抗本质是力控”可作为典型接口的粗略记忆，但不是严格定义。更准确的说法是：导纳用力信息生成运动，阻抗用运动信息生成力／力矩；是否跟踪指定接触力是另一个问题。

2. 阻抗：规定偏移后产生怎样的恢复作用

2.1 期望动态关系与实际控制律

先看固定参考、单方向平移。设 e=x−xd，一种期望的受力响应是：

mde¨+bde˙+kde=fext.

md,bd,kd 分别是期望质量（kg）、阻尼（N·s/m）和刚度（N/m），fext 是环境作用在机器人上的力（N）。没有外力时，稳定的系统回到参考位置；有外力时，系统按设定的动态关系偏移。

这是一条期望闭环关系。仅把弹簧、阻尼反馈叠加到力矩命令上，不会自动实现任意指定的 md；物理惯量、耦合和模型残差仍然存在。若需要惯量整形或动力学解耦，还需额外设计并验证，不能把期望方程直接当作已实现的响应。

2.2 关节阻抗与笛卡尔阻抗

关节阻抗直接根据关节误差计算关节力矩：

τcmd=Kq(qd−q)+Dq(q˙d−q˙)+τff.

对转动关节，刚度单位为 N·m/rad，阻尼单位为 N·m·s/rad。常见 MIT 风格驱动器就可执行这类局部反馈，见MIT 模式。不需要先算“每个关节的力”再转换成力矩。

笛卡尔阻抗则在工具参考点计算恢复力旋量，再映射到关节：

wcmd=Kxex+Dxev,τcmd=JTwcmd+τff.

ex 包括“目标减实际”的位置误差和适当定义的局部姿态误差；ev 包括线速度、角速度误差，wcmd 按力（N）、力矩（N·m）排列。姿态误差不是任意相减欧拉角，须与角速度和 Jacobian 的坐标一致。平移刚度以 N/m 计，转动刚度以 N·m/rad 计，不能把六个分量当作同一单位。

这里 wcmd 是控制器请求施加的恢复作用，wext 是环境作用在机器人上的外力，两者不能直接等同。映射依据见雅可比、Twist 与 Wrench。

2.3 哪一种更适合接触任务

选择考虑 常见独立关节阻抗 笛卡尔阻抗
参数的直觉 各关节容易转动还是难转动 工具沿法向、切向或转动方向有多软
计算与反馈部署 较直接，容易放在驱动器本地高速执行 需要 FK、Jacobian、任务坐标和姿态误差处理
末端柔顺方向 由关节参数与构型共同决定，换姿态后效果会变 可以直接按接触任务定义软硬方向
冗余与构型管理 直接约束各关节参考姿态 通常另设零空间控制管理肘部、限位等
实际精度 受刚度、摩擦、补偿、传感和执行能力影响 同样受这些因素影响，不天然更精准

低刚度关节通常会同时改变工具位置和姿态，不一定只沿想让步的方向运动。对于策略输出末端位姿、希望法向柔顺而切向保持轨迹的任务，笛卡尔阻抗的表达更直接。

两者没有不可逾越的能力差异：在小位移、忽略预载引起的几何刚度项时，末端弹性势能可拉回关节空间，得到局部关系：

Kq≈JTKxJ.

但这种 Kq 一般非对角、随构型变化，并且在冗余系统中不约束所有零空间方向；不是常见的“每个关节一个固定增益”，也不能任意反推唯一末端刚度。完整设计还需考虑零空间、耦合及实际动力学。

若主要关注整条手臂的关节行为或本地高速保护，关节阻抗很实用；若主要关注工具接触方向，笛卡尔阻抗通常更便于设计。但二者都不能自动保证任意连杆碰撞时安全。

3. 导纳：用外力修改要跟踪的运动

3.1 在本项目中需要输入什么、输出什么

以平移单方向为例，导纳维护修正量 δx 和修正速度 δx˙，按下式演化：

maδx¨+baδx˙+kaδx=fext.
输入／状态 来源与含义
名义目标 xnom 由策略位姿增量按明确的规则更新
外力 fext 力传感器或可靠外力估计，需补偿偏置与工具负载，并转换到任务坐标
参数 ma,ba,ka 虚拟质量、阻尼、刚度，单位分别为 kg、N·s/m、N/m
上周期修正位置、速度 导纳积分状态，不能每周期无意清零

导纳根据力和已有状态计算修正加速度，再通过离散积分更新速度和位置。最终输出：

xcmd=xnom+δx.

接下来由位置内环跟踪 xcmd：末端目标经过 IK 或微分 IK 转成关节目标，关节伺服再驱动电机。位姿输出不是机械臂已经移动；仍需等待真实运动并读取下一周期的力反馈。

典型链路：策略增量 → 名义参考 → 导纳修正 → 运动学转换 → 位置伺服 → 真实运动与接触 → 力反馈返回导纳。 IK 的作用见轨迹与控制链路。

数值示例：实际位置为 100 mm，策略把名义目标更新为 101 mm；若当前导纳修正为 −0.4 mm，下发的位置目标就是 100.6 mm。位置内环努力跟踪 100.6 mm，而不是原始的 101 mm。导纳可以改善受力响应，但没有免费保留原始目标精度。

3.2 受力退让不等于跟踪指定压力

在正刚度、稳定、外力恒定时，上述修正式的平衡量为：

δx=fextka.

例如向右为正、墙在右侧，墙的反力为负，导纳就生成向左的修正。若反力为 −10 N、刚度为 5000 N/m，静态修正为 −2 mm。撤去外力后，正刚度倾向于让修正回到零。

但它没有要求“压力必须为 10 N”。如果策略持续把名义目标推入墙内，有限柔顺性仍可能使接触力不断增大。限力还需目标管理、接触力闭环或停止／回退逻辑等设计。

若目标是稳定压力，可在选定法向使用力误差生成运动。定义位置增大为压向表面，fm 为正的实测压力大小，fd 为目标压力：

max¨c+bax˙c=fd−fm.

压力小则向内运动，压力大则退让；持续接触、稳定、无饱和并达到静止时，有 fm=fd。这里没有把位置拉回某一锚点的弹簧项，因而不要求一个固定的位置偏差来支撑力误差。

两个方程使用不同力定义：前者为带方向的环境外力，后者为接触压力大小之差。程序必须统一符号后实现，不能直接替换变量名。

没有接触时 fm=0，非零目标压力会持续驱动向前；传感器偏置也会造成错误运动。因此必须处理接近、建触、调力和脱离状态，并限制位移、速度和积分状态。法向力控与策略运动应明确仲裁，不能同时无限累积互相冲突的法向目标。

3.3 位姿增量语义为什么会影响行为

若增量相对上一次名义目标累积：

xnom,k+1=xnom,k+Δxk,

机器人暂时不动时，参考误差仍会增加，可能最终克服摩擦，也可能积累为过大的接触力和脱离后的突然运动。

若增量相对当前实际位置：

xnom,k+1=xactual,k+Δxk,

机器人不动且每次增量相同时，目标只领先一个固定小量，误差不会自动累积；低刚度下恢复力可能始终不足。该规则还会改变外层导纳的整体响应，不能直接把导纳内部参数当作实际末端刚度。

必须保留策略训练时的语义，并明确参考是否已经含导纳修正，防止重复累加。三维姿态增量还要说明在世界系还是工具系表达、旋转是左乘还是右乘；不能直接逐项相加旋转矩阵或四元数。参见姿态与坐标变换。

4. 位置精度：先分清是哪一种偏差

4.1 四个位置不一定相同

  • 策略名义目标：策略原本希望去哪。
  • 控制器参考：导纳、限速或轨迹处理后，实际下发的目标。
  • 反馈位置：通常由编码器和 FK 计算得到。
  • 物理工具位置：真实工具在空间中的位置，还受结构形变、TCP 和几何标定误差影响。

名义目标与修正参考的差是主动让步；参考与反馈的差是跟踪误差；反馈与真实工具位置的差可能是标定或机械误差。只看编码器到位，无法证明真实工具准确到位。

4.2 有限刚度为什么需要偏移

固定参考、重力等已准确补偿的单方向阻抗中，设 u 为机器人沿该方向施加的驱动力（N）：

u=kr(xr−x)−brx˙.

设机器人受到大小为 fe、方向阻碍前进的接触反力。静止且未饱和时：

kr(xr−x)=fe,xr−x=fekr.

例如刚度 1000 N/m、压力 10 N，对应参考与实际相差 10 mm。这是虚拟弹簧产生恢复力所需的偏移，不一定是控制失败；参考甚至可以位于物体内部，它在这里更像弹簧锚点。

自由空间、无残余负载、无摩擦且系统稳定时，正刚度阻抗仍可最终收敛到任意小的固定位置变化。柔顺并不必然造成稳态精度差，但刚度低通常意味着相同负载残差造成更大偏移，响应速度也可能降低。

4.3 为什么真机小增量可能不动

单关节静止、补偿后，目标改变 Δq，初始新增力矩近似为：

Δτ=kqΔq.

若该力矩不足以克服静摩擦阈值 τs 或其他残余负载，关节可能保持不动。简化静摩擦条件为：

|kq(qd−q)|≤τs.

低刚度使相同小增量产生的力矩更小；静止、目标速度为零时，阻尼项不能提供额外启动作用。目标若持续累积，可能出现积累后突然滑动的黏滑现象。

解决办法应对应原因：改善重力／摩擦补偿、减少传动死区、提高必要方向刚度、检查量化与增量语义。积分或扰动估计可减小慢变残差，但强行消除外力造成的偏移会改变柔顺关系；接触与饱和时还需处理积分累积。盲目加阻尼不能消除静态误差。

此外，微分 IK 接近奇异、关节速度限幅、策略抖动和控制滞后也会导致小增量跟不上，参见SVD 与 IK。

4.4 为什么同一方向的位置和力不能任意指定

用线性接触模型解释。定义 x 增大为压向物体，接触起点为 xs，环境等效刚度为 ke：

fe=ke(x−xs),x≥xs.

指定压力 fd 后，对应的位置必须是：

x=xs+fdke.

因此位置和压力必须与真实环境相容。若环境刚度为 100 N/mm，20 N 压力对应压入量 0.2 mm；同时要求零压入量就与该模型冲突。

与虚拟弹簧联立，在持续接触、线性静态条件下：

fe=krkekr+ke(xr−xs).

这解释了真机迁移中的核心风险：同一参考轨迹，遇到不同表面位置和刚度，会产生不同接触力。提高机器人刚度可减少受力偏移，却也可能增加几何误差引起的力变化。

若任务优先保证压力，应允许法向位置调整；若还要求精确加工深度，需要结合几何测量、工具／工件形变和接触模型，不能只凭一个力值推断深度。

5. 力位方向由接触几何决定，不限于世界 XYZ

5.1 倾斜平面：把柔顺方向对准法向

设单位表面法向为 n，三维平移刚度矩阵可以取：

Kx=knnnT+kt(I−nnT).

kn 是法向刚度，kt 是两个切向刚度。取法向软、切向硬，就允许向外退让，同时保持沿面轨迹。该矩阵在世界系下一般带交叉项，不是简单地分别调整固定 XYZ 三个增益。

也可在正交任务坐标系配置增益，再用旋转矩阵变换到世界系。姿态方向可以单独设置顺应性；平移软不意味着转动也软。

各向异性阻抗与显式力位混合应区分：法向低刚度、切向高刚度只是软硬分配；法向闭环跟踪指定压力、切向跟踪运动，才是显式的力位任务分工。两者都可沿任意任务方向定义，不必沿世界坐标轴。

5.2 边与角：先判断实际约束数

接触情形 忽略摩擦时的局部平移约束理解
点接触光滑平面 一个法向约束，两个切向可运动
同时接触两个法向独立的平面 两个法向约束，沿交线可运动
同时接触三个法向独立的平面 三个平移方向均受约束
接触一条锐边或一个尖角 要结合双方几何和实际接触状态，不能仅凭名称判断约束数

例如工具贴着内直角两侧面沿槽移动，可在两个侧面法向调力／柔顺，沿交线控制运动。法向 n1,n2 不平行时，沿槽单位方向为：

t=n1×n2‖n1×n2‖.

非正交的两个法向不能简单当作两个独立正交轴。更一般地，可将持续接触、无穿透的瞬时平移约束写成 Av=0，其中各行为法向转置；rank(A) 描述独立约束数，零空间描述允许的平移方向。这是理想局部模型，不包含接触脱离和摩擦切换。

若工具还发生转动，接触点速度包含 ω×r，约束会同时涉及平移和转动；面接触、偏置接触也可能约束姿态。不能把上表直接推广成完整六维约束数。插入任务也不是一律“轴向力控、横向硬位控”：横向碰孔壁后，横向同样需要柔顺或力限制。

5.3 为什么边角比倾斜平面更困难

沿面到达边缘时，接触可能从一个面切换到另一面，或暂时变成多面接触。原本允许的切向运动可能转为向另一表面内部挤压。此时需要几何信息、接触状态判断和控制方向更新，并对目标力、刚度、参考和积分状态进行平滑衔接。

不能简单用腕部合力方向当作唯一法向：摩擦会偏转合力，多点接触会叠加，单个六维传感器通常不能唯一分解所有接触点的力。未知接触时先允许更多方向退让，是一种可考虑的策略，但仍需结合任务验证。

7. 项目中的选择与验证顺序

7.1 先决定需要什么接触行为

任务重点 可以考虑的方案 代价与前提
按策略移动，遇到外力适当让步 导纳修正＋位置内环 需要可信力反馈；内环跟踪好不等于原始轨迹不偏；需处理延迟和修正状态
直接定义工具在各方向的软硬 笛卡尔阻抗＋力矩执行 需要可靠力矩接口、运动学和补偿；简单版本不必用接触力反馈，但不保证指定压力
主要管理关节行为与本地高速反馈 关节阻抗 末端柔顺方向随构型变化，需要检查实际工具响应
沿面运动且保持明确压力 法向接触力闭环＋切向运动控制 导纳或力矩路径均可实现，必须明确目标力、坐标和接触状态

有接触不意味着所有方向、所有阶段都应调软。应先区分自由运动、接近、建触、稳定交互和脱离：何时优先位置、何时优先力、哪些偏差可以接受，再选择实现。

7.2 为什么换控制器还会影响上层策略

如果策略训练时使用刚性位置跟踪，部署时改为导纳或低刚度阻抗，相同动作对应的真实运动和接触力就变了。新增导纳状态、滤波和延迟也改变了策略所见的系统。应在仿真或受控实验中对齐控制器、增量语义与观测反馈，再评价策略迁移；不能默认只是“下面更安全了一点”。

直接笛卡尔阻抗不必先求目标关节位置，但仍需要 FK、Jacobian 和构型管理；导纳＋位置内环通常经过 IK／微分 IK。若退让方向恰好接近运动学退化方向，两条路径的实际接触行为都可能受限，详见SVD 与 IK。

7.3 建议记录什么，才能区分问题来源

在自由空间和逐步接触实验中，同步记录策略增量、名义目标、修正目标、实测关节／末端状态、原始和补偿后力反馈、力矩与限幅状态、采样时间和延迟。先查误差在哪层出现，再调整对应参数。

例如，修正参考本身已经退回，说明外层主动让步；修正参考没变但关节没动，可能是摩擦、伺服或 IK；编码器显示到位而工具不准，则需查几何和结构。这些是后续建议验证方法，本轮未完成实机实验，也未选定参数。

06 EMA 滤波与反馈延迟

创建日期：2026-11-09
最近更新：2026-11-09

本章解决什么问题

EMA 是控制算法吗？为什么曲线更平滑，控制效果却可能变差？怎样把平滑系数与实际采样时间联系起来？

快速回顾

指数移动平均（Exponential Moving Average，EMA）是一阶递归低通滤波器，可用于测量、速度估计或指令平滑，本身不决定控制目标。滤掉快速变化，也会引入相位滞后；闭环中必须评估这一代价。

1. 递推式与记忆长度

yk=αxk+(1−α)yk−1,0<α≤1.

xk 为当前输入，yk 为输出。α=1 时不平滑；α 越小，过去样本权重衰减越慢。展开可见旧样本权重按 (1−α)j 衰减，不是对固定窗口等权平均。

对一阶连续低通 τy˙+y=x，假设采样间隔内输入保持，精确离散化给出：

α=1−exp(−Ts/τ).

Ts 为采样周期，τ 为时间常数。常见近似 α=Ts/(τ+Ts) 来自后向欧拉离散化，二者在小采样周期下接近，但不是完全相同的定义。采样间隔变化时，可按实际间隔计算 αk，而不是默认线程调用频率恒定。

示例：希望 τ=0.05s，Ts=0.01s 时精确离散系数约为 0.181；这只是算例，不能直接用作你的驱动器增益或滤波配置。

2. 为什么滤波会影响闭环

EMA 的传递函数为：

H(z)=α1−(1−α)z−1.

高频噪声被衰减，同时动态信号也被延后。对于独立零均值白噪声，稳态输出方差为输入方差的 α/(2−α)；该结论不适用于把固定偏置消除，也不说明真实接触信号都该被滤掉。

在关节阻尼反馈 τd=−Kdq˙^ 中，滤波过重会让速度估计滞后于真实速度。控制器可能继续沿用旧方向施加力矩，降低有效阻尼或稳定裕度。应结合采样、通信和执行器延迟验证闭环，而不是只看曲线是否好看。

3. 联系项目，哪些地方适合，哪些要谨慎

使用位置 目的 主要代价／检查
关节差分速度 减少编码器量化与差分放大噪声 使用真实时间戳，检查速度相位与阻尼反馈
力传感器测量 减少高频测量噪声 碰撞峰值也可能被削弱；保留原始通道检查峰值
RL 动作目标 降低指令抖动 改变实际动作动态，应在训练和部署中保持一致
重力参数辨识数据 降低部分随机波动 不混合不同姿态、速度或方向段，避免滞后造成配对错误

历史七轴臂纯重力补偿不含速度反馈，不能因为速度曲线噪声大就认定必须给重力律加 EMA。只有该量进入控制或辨识时，才评估其噪声如何影响结果。对拧盖策略追加动作滤波也不是无成本修复：策略训练时没见过的延迟可能改变抓握和换指时机。

工程中一阶低通、滑动平均、模型观测器和 Kalman 滤波都有应用。EMA 计算和调试简单；若有可信的动力学与噪声模型，状态估计器能进一步融合信息，但会增加建模和失配问题。没有一个滤波器普遍适用于所有传感通道。

01 坐标变换与姿态表示

创建日期：2026-11-09
最近更新：2026-11-09

本章解决什么问题

相机、机器人基座、工具和物体分别使用不同坐标系，如何把同一个点、方向或姿态转换到另一个坐标系？旋转矩阵、欧拉角、四元数和 6D Rotation 分别表达什么？

快速回顾

  • 坐标变换改变同一几何对象的表示；主动运动改变几何对象本身，必须先区分语义。
  • 本章以 TAB 表示“把 B 系坐标转换到 A 系”，采用列向量。串联变换按相邻下标抵消。
  • 三维旋转只有三个自由度。旋转矩阵、四元数、6D 表示使用的数字数量不等于自由度数量。
  • 世界系旋转左乘、局部系旋转右乘，需要结合所操作的旋转或完整位姿解释；不能忽略旋转中心。

1. SO(3) 与 SE(3)

特殊正交群（Special Orthogonal Group）SO(3) 中的旋转矩阵满足：

RTR=I,detR=1.

列向量表示旋转后坐标轴在参考系中的方向。正交条件保持长度和夹角，行列式为正排除镜像反射。

特殊欧氏群（Special Euclidean Group）SE(3) 将旋转和平移组合为刚体位姿：

TAB=[RABpAB01],xA=RABxB+pAB.

pAB 是 B 系原点在 A 系的位置，位置单位通常为 m；RAB 无量纲。方向向量不加平移：dA=RABdB。不能把点和方向混用。

变换的复合与逆为：

TAC=TABTBC,TBA=TAB−1=[RABT−RABTpAB01].

例如，相机观测物体的位姿为 TCO，相机到基座的外参为 TBC，则物体在基座下的位姿为 TBO=TBCTCO。该例只说明坐标链，不意味着外参已经标定。

2. 姿态表示及其边界

表示 数值形式 关键边界
欧拉角（Euler Angles） 三个角 必须声明旋转顺序、内禀／外禀约定；存在万向节锁
旋转矩阵 九个数 需满足正交和行列式约束；矩阵逐元素插值通常不是旋转
单位四元数（Quaternion） 四个数 需归一化；确认标量在前还是在后；正负四元数代表相同旋转
轴角／旋转向量 单位轴及角／三维向量 在特殊角度附近需处理分支；适合构造局部旋转误差
6D Rotation 两个三维向量 需正交化；通常用于网络回归，不是六个物理旋转自由度

四元数插值常使用球面线性插值（SLERP）。比较相邻四元数时需处理符号连续性，否则同一姿态可能被误判为大幅跳变。

对 6D 表示，网络输出 a1,a2，通过 Gram–Schmidt 构造：

b1=a1‖a1‖,u2=a2−(b1Ta2)b1,b2=u2‖u2‖,b3=b1×b2,R=[b1 b2 b3].

若输入接近零或共线，归一化会退化，需要数值保护。它的主要意义是改善学习中的表示连续性，不是减少旋转的物理自由度。

3. 旋转中心与左乘、右乘

设 R 把工具系方向变到世界系。在世界系施加旋转 RΔ 时，R′=RΔR；绕工具当前局部轴旋转时，R′=RRΔ。

但把完整位姿左乘一个无平移的旋转变换，会同时改变工具位置：

[RΔ001][Rp01]=[RΔRRΔp01].

这对应绕世界原点转动。若需求是“工具位置不变，仅绕世界轴原地改变朝向”，应设置 R′=RΔR、p′=p。这是本地 SDK 位控审查中出现过的关键区别。

例如工具位于 (1,0,0) m，世界 z 轴旋转 90°：完整左乘将位置变为 (0,1,0) m；原地改变朝向则位置仍为 (1,0,0) m。

4. 角速度与局部姿态误差

定义叉乘矩阵 [a]×b=a×b。当 R 为体到世界旋转且角速度在世界系表达时：

R˙=[ωW]×R.

若角速度在体坐标系表达，则 R˙=R[ωB]×。固定在刚体上的点，相对所选参考点的向量为 r，其相对线速度是 ω×r。

姿态控制不应直接对旋转矩阵逐元素相减当作三维角误差。局部可使用：

eR=Log(RdRT)∨.

这里 Log 是旋转的矩阵对数，∨ 把反对称矩阵变为三维旋转向量；该误差在世界系表达，单位为 rad。接近 180° 时需注意分支与数值稳定性。

02 雅可比、Twist 与 Wrench

创建日期：2026-11-09
最近更新：2026-11-09

本章解决什么问题

关节速度如何变成末端速度？为什么末端力可用雅可比转置映射为关节力矩？改变力矩参考点与仅旋转坐标轴有什么不同？

前置知识：坐标变换与姿态表示。以下采用固定基座机械臂，广义速度等于关节角速度；浮动基座或四元数配置不能直接按同一方式处理。

快速回顾

  • 正运动学（Forward Kinematics，FK）映射位置，雅可比矩阵（Jacobian）映射当前构型下的瞬时速度。
  • 本章六维量均按“线性在前、角量在后”排列；库的排列约定必须另行核对。
  • 线速度、力矩依赖参考点；角速度与合力不依赖参考点，但都依赖表达坐标轴。
  • τ=JTF 来自功率一致性，要求速度和力使用匹配的坐标、参考点及方向。

1. 几何雅可比

对末端指定点 P，定义几何速度：

ξP=[vPω]=JP(q)q˙.

q 是关节角（rad），vP 单位为 m/s，ω 单位为 rad/s；雅可比不同的行具有不同物理尺度。

当所有向量在同一参考系表达时，旋转关节 i 的列为：

JP,i=[zi×(pP−oi)zi].

zi 为单位关节轴，oi 为轴上一点。移动关节的列为 [ziT,0T]T。旋转关节到末端的距离越远，单位关节角速度产生的线速度通常越大。

几何雅可比与欧拉角的解析雅可比不同：欧拉角导数一般不等于角速度。

2. Twist 与参考点

刚体瞬时运动常用运动旋量（Twist）表示。不同书籍和库对六维排列及参考原点的定义不同；仅知道“六维速度”还不足以选择转换矩阵。

令 r=pQ−pP，所有量用同一坐标轴表达，则：

vQ=vP+ω×r=vP−[r]×ω.

所以改变参考点时，线速度要加入平移相关项；仅改变表达轴时，线速度和角速度分别乘同一个旋转矩阵即可。

若采用空间 Twist T˙T−1 的线性在前表示，且 TAB 按上一章定义，则伴随变换（Adjoint）为：

AdTAB=[RAB[pAB]×RAB0RAB].

该空间 Twist 的线性分量不一定就是工具原点的几何线速度。不能把完整伴随变换无条件用到“同一点、仅换轴”的数据上。

3. Wrench、功率与雅可比转置

力旋量（Wrench）以某点为参考：

FP=[fmP].

f 是合力（N），mP 是关于 P 的合力矩（N·m）。机械功率为：

P=fTvP+mPTω=FPTξP=FPTJPq˙.

与关节功率 τTq˙ 比较可得：

τ=JPTFP.

若 FP 定义为环境作用在机器人上的力，右式是环境产生的广义力；若控制器要静态抵消它，所需执行器力矩还需取相应反号并叠加重力等项。

若速度通过 ξA=AdTξB 变换，为保持功率，配对力旋量满足 FA=AdT−TFB，不能照抄速度变换。

4. 力矩参考点变换与杠杆臂

令 r=pQ−pP，把关于 P 的 Wrench 移到 Q：

fQ=fP=f,mQ=mP−r×f.

示例：r=(0,0,0.2) m，f=(10,0,0) N，关于 Q 的力矩为零，则关于 P 的力矩是 (0,2,0) N·m。换参考点不会改变合力，却会改变合力矩。

若用 mQ=mP−r×f 从远端参考点估算接触端力矩，力误差会被杠杆臂转换为力矩误差。这是精密插接中“传感器有力矩读数”仍不代表端面微弱力矩可靠的原因之一。

5. 数值检查与易错点

可用小关节扰动检查平移雅可比：

Jv,i≈p(q+ϵei)−p(q−ϵei)2ϵ.

旋转部分应使用旋转对数构造小角变化，并统一表达轴，不能直接微分欧拉角冒充角速度。另可任选小速度和力，检查 FTJq˙ 与 (JTF)Tq˙ 是否一致。

Pinocchio 的 LOCAL、WORLD、LOCAL_WORLD_ALIGNED 涉及表达轴和参考原点的区别；WORLD 不是简单把末端几何雅可比的两组三维量旋转一下。具体使用见动力学算法章节。

03 SVD、伪逆与逆运动学

创建日期：2026-11-09
最近更新：2026-11-11

本章解决什么问题

给定末端目标，解析法和数值法分别怎样求关节姿态？奇异值、条件数与真实运动能力如何对应？IK 有没有解、求解器能否找到解、找到后能否执行，为什么是不同问题？结合位姿增量接触任务讨论方法选择，并保留已有七轴 demo 的数值实现分析。

快速回顾

  • 逆运动学（Inverse Kinematics，IK）解完整非线性位姿方程；Jacobian 描述某个构型下的局部瞬时运动，不能直接代替全局可达性判断。
  • 解析法利用机构结构显式求解或枚举有限分支；数值法通过局部迭代减小误差，两者都要检查限位、碰撞和模型误差。
  • 奇异值分解（Singular Value Decomposition，SVD）把运动映射拆成相互配对的关节／末端方向；小奇异值意味着对应方向运动效率低，反解可能放大输入误差。
  • 条件数描述方向间的相对差异，不能单独判断 IK 有无解或执行能力；六维任务必须先约定平移／转动尺度。
  • 阻尼最小二乘以任务误差换取有限的关节变化；它不让不可达目标变得可达，也不自动实现关节限速和避碰。
  • IK 有解可以恰好处于奇异构型；求解失败也可能只是初值或算法问题。规划还要检查整条连续路径和执行约束。

1. 解析法：从完整运动学方程求解

正运动学（Forward Kinematics，FK）由关节配置得到末端位姿 T=f(q)；IK 给定 Td，寻找满足 f(q)=Td 的关节配置。这里 T 包含位置与姿态，不能只满足位置就声称完整位姿 IK 成功。

解析法（Analytical Method）利用机构几何和代数结构，推导显式公式或有限求解步骤，不依靠从初值逐次下降来获得每个解。并非所有机构都容易得到简单解析反解；冗余机构还可能需要先指定一个冗余参数或参考条件。

平面两连杆的推导与解分支

只要求末端二维位置，不要求末端姿态。设连杆长度为 l1,l2（m），关节角为 q1,q2（rad），目标为 (x,y)（m）：

x=l1cosq1+l2cos(q1+q2),y=l1sinq1+l2sin(q1+q2).

两式平方相加后，由余弦关系得到：

c2=cosq2=x2+y2−l12−l222l1l2.

忽略限位时，|c2|>1 表示位置不可达；否则通常有两种肘部构型：

q2=atan2(±1−c22,c2),
q1=atan2(y,x)−atan2(l2sinq2,l1+l2cosq2).

正负号对应不同分支，边界处两支可能合并。完全折叠、等长连杆且末端在基点等退化情况需单独处理，不能把未定义的角度计算当正常解。浮点误差只允许在容差内修正略微超出区间的数值，不能把明显不可达目标强行截断成可达。

该例解释了三个实际问题：同一末端位置可以有多个关节解；解析法也要选分支与检查限位；解析解使用的是几何模型，不能自动消除真实机器人标定误差。

2. 从局部运动到线性方程

对固定基座机械臂，记局部任务运动为 x，关节位置为 q，其速度满足 x˙=J(q)q˙。目标减当前的位置和局部姿态误差组成 e，小步近似为：

J(q)Δq≈e.

平移误差以 m 计，姿态误差以 rad 计，必须使用任务权重或尺度进行平衡。姿态误差和雅可比应在一致坐标轴下表达；大角误差下还应考虑所选误差映射的微分，不能把局部近似当作任意步长下的精确关系。

3. SVD 与伪逆

对实矩阵：

J=UΣVT,J+=VΣ+UT.

U,V 分别给出输出、输入空间的正交方向，非负奇异值 σi 给出对应伸缩比例。伪逆对非零奇异值取倒数；数值计算需给出截断容差。

Δq=J+e.

该式给出最小范数最小二乘解：先尽量减小残差，再在同样最优的解中取最小范数。它不意味着所有目标都可精确达到。

奇异值的数学方向与运动含义

对配对的单位方向，有：

Jvi=σiui.

vi 是关节协同运动方向，ui 是它产生的末端运动方向。若 q˙=avi，则 x˙=aσiui；希望末端沿 ui 以幅值 b 运动时，最小范数速度分量为：

q˙=bσivi,σi>0.

因此小奇异值表示同样关节运动产生的末端运动少；反过来，指定末端运动需要更大的关节速度。方向通常是多个关节的组合，也不一定沿世界 XYZ。

纯平移、两个转动关节的简化局部数值示例：

J=[0.2000.002] m/rad.

末端沿两个方向分别要求 0.01 m/s 时，对应关节组合速度分别为 0.05 rad/s 与 5 rad/s。不是“小末端速度一定对应小关节速度”。同样，小位移反解得到的大步长也可能超出线性近似范围。

条件数：相对不均衡，不等于绝对能力

对满行秩任务雅可比，二范数条件数为：

κ2(J)=σmaxσmin.

条件数接近 1，说明在选定尺度下各任务方向相对均衡；很大时，某些方向运动效率远低于其他方向；失去行秩时通常视为无穷大。冗余机械臂即使满行秩也有关节零空间，不能把这些正常冗余方向误认为任务失秩。若计算库只报告非零奇异值之比，还需独立检查秩和截断阈值。

条件数不提供整体速度尺度：I 与 0.001I 的条件数都是 1，但产生同样末端速度的关节速度需求相差千倍。条件数大也不表示每一步都困难，目标若主要沿大奇异值方向，仍可能容易执行。

六维 Jacobian 同时含 m/s 和 rad/s，关节还可能混合转动与移动。把 m 改为 mm 就能改变原始奇异值和条件数，机械能力却没有变化。工程阈值必须先定义尺度，例如：

J¯=SxJSq−1,x˙¯=Sxx˙,q˙¯=Sqq˙.

Sx,Sq 可根据任务速度尺度和关节速度尺度选定，使归一化量可比较。随后同时检查最小奇异值、目标方向和各关节限值，不能套用脱离单位与任务的统一条件数阈值。二范数球下的能力描述也不等于每个关节独立速度限制形成的真实可行集合。

4. 阻尼最小二乘

阻尼最小二乘（Damped Least Squares，DLS）求解：

minΔq ‖JΔq−e‖22+λ2‖Δq‖22,λ>0.

其解可写为：

Δq=JT(JJT+λ2I)−1e.

每个奇异方向的增益从 1/σi 变为 σi/(σi2+λ2)。因此小奇异值不再造成无界放大，代价是增加任务误差。实现时解线性方程，不必显式计算矩阵逆。

实际迭代还需要步长限制、限位检查、停止阈值和失败返回。提高阻尼不能解决被障碍物隔开的目标或不可达目标。

5. 冗余与零空间

对速度任务，在使用精确伪逆时：

q˙=J+x˙d+(I−J+J)z.

第二项位于雅可比零空间，不改变当前瞬时任务速度，可用来远离限位或接近参考姿态。例如选 z=−k∇H(q)，H 为姿态或限位代价。

零空间性质是局部、瞬时的；有限步执行仍要重算 FK 和约束。若用阻尼伪逆代替精确伪逆，I−J#J 通常不再是严格零空间投影，次任务可能扰动主任务。后续还需区分运动学投影与动力学一致投影。

6. IK 有没有解，与奇异性究竟是什么关系

完整方程的解、局部运动和数值收敛是三个问题

  • 数学／约束可行性：是否存在满足目标位姿、限位和其他声明约束的关节配置。
  • 局部运动能力：某个配置附近能否以有限关节速度产生指定末端速度。
  • 求解器结果：某个初值、迭代预算和停止阈值下，算法有没有找到合格解。

Jacobian 和条件数属于当前构型 q，不只属于目标位姿。同一目标可有多个 IK 解，各解的运动学条件可能不同。完整几何 IK 有解，也不代表加入限位、碰撞后仍有可行解。

一个同时解释有解、无解和奇异的例子

仍看不要求末端姿态的平面两连杆。其位置 Jacobian 满足：

detJ=l1l2sinq2.

两根连杆各 1 m，完全伸直时 q1=q2=0，末端位于 (2,0)。此构型 Jacobian 奇异，但它本身就是目标 (2,0) 的一个准确 IK 解。

保持同一个初始构型：

目标（m） 几何 IK 为什么
(2, 0) 有解且该解奇异 完全伸直就能到达
(1.9, 0) 有解 弯曲关节可以收回
(2.1, 0) 无解 超过最大臂展

初始 Jacobian 和条件数完全相同，三个目标的可达性却不同。因此，当前奇异不能判断目标有无解，条件数也不能。

向内收回为什么有解却局部难走？取 q1=−θ,q2=2θ，末端保持 y=0，有：

x=2cosθ≈2−θ2(m).

在 θ=0 处轴向一阶变化为零，但有限弯曲会产生二阶的轴向收缩。Jacobian 没表达这个方向的一阶运动，不表示完整非线性方程无法通过有限运动到达内部目标。若要求从奇异点立即以非零轴向速度移动，则又涉及不可实现的瞬时速度要求。

满秩能保证什么，求解失败能证明什么

对于光滑的局部任务坐标映射，如果某个解处 Jacobian 满行秩，且该解位于允许配置的内部、附近没有额外约束阻挡，则目标附近足够小的任务变化可以由附近关节变化实现。方阵非奇异时还可得到局部唯一的逆；冗余时解通常不唯一。这是局部结论，不是所有远处目标可达的保证，也不是整条路径可行的证明。

数值 IK 从伸直构型出发时，轴向误差可能正交于当前 Jacobian 的值域，普通伪逆步为零；DLS 也不会凭空生成缺失的一阶方向。换成稍弯曲的初值、解析分支或其他搜索方式可能找到真实存在的解。反之，再好的初值也不能让超出臂展的目标变得可达。

因此求解器报失败后，应检查最终 FK 残差、限位与碰撞、秩／尺度、初值和迭代停滞原因。只有具备额外证明或完整分析，才能把“没有找到”判定为“没有解”。

8. 几何雅可比与残差雅可比为什么不完全一样

历史七轴臂 demo 把 IK 写成带关节上下界的非线性最小二乘。设残差为“当前减目标”：

r(q)=[wp(p(q)−pd)wRLog(RdTR(q))],minqmin≤q≤qmax12‖r(q)‖22.

wp,wR 用于平衡 m 与 rad；Log 在此取旋转向量形式。残差雅可比定义为 Jr=∂r/∂q，局部模型是 r(q+Δq)≈r(q)+JrΔq，因此修正方向应解 JrΔq≈−r。这与前面用“目标减当前”写成 JΔq≈e 的符号约定不同。

几何雅可比描述关节速度到末端线／角速度；残差雅可比还要包含权重、坐标表达和姿态误差映射的导数。小误差时两者有简单近似关系，大旋转下不能直接忽略 Log 的微分。Pinocchio 官方 IK 示例使用 Jlog6 修正位姿误差的导数，说明即使已有机器人雅可比，仍需对接所选残差。

对第 j 个关节，中心有限差分为：

(Jr):,j≈r(q+hej)−r(q−hej)2h.

ej 为单位基向量，h 为小关节扰动。对七轴问题，一次完整中心差分通常需约 14 次扰动残差求值；实际求解器可复用、并行或在边界改用单侧差分。这些扰动在模型计算中进行，不要求实机逐次试动。

h 太小会受浮点消减误差影响，太大会破坏局部近似。改变步长复核导数，并与解析／库雅可比做方向检查，比看到求解器返回成功更能定位符号与坐标问题。

9. 为什么入门 demo 用 least_squares，实际又怎样选

路线 选择理由 仍需自己处理
least_squares 加数值差分 小规模快速验证，可直接给关节 bounds，信赖域管理步长 残差量纲、碰撞、最终可执行性；函数求值成本
DLS／LM 加正确残差导数 便于利用运动学结构、降低反复 FK 成本 限位、步长、阻尼、失败与实时预算

SciPy 的 TRF 支持变量 bounds；LM 不能直接接受这些 bounds。选了 least_squares 不代表碰撞约束也自动存在；遇到不可达或受阻目标，仍要检查最终位置／姿态误差和碰撞。

科研与工程工具中，解析反解、DLS、受限最小二乘和 QP 都有成熟用例。SciPy 与 Pinocchio 的公开示例分别支持上述两条路线，但不能据此断言工业机械臂统一使用某一种。对当前七轴臂，先用现有最小二乘跑通模型与限位；若进入高频连续控制、或反复 FK 成为瓶颈，再根据计时与约束需求选择正确的解析导数、DLS 或 QP。

10. 从测试目标到真实任务：初值、连续性与模型误差

“先扰动关节角、用 FK 生成可达目标，再做 IK”是模型自洽测试，不是实机任务目标的来源。真实目标来自规划、视觉或操作者；初值通常取当前实测关节角，连续轨迹中可用上一有效解热启动，并持续核对真实状态。

七轴同一末端目标可能有多解。用参考姿态、限位余量和连续性代价选解，防止相邻目标之间跳支路。多初值重启可增加找到其他局部解的机会，但不能保证全局成功；每个候选还要经过约束和路径验证。

解析 IK 和数值 IK 都在求同一近似模型的反解。更换求解器不能自动修正关节零位、连杆几何、TCP 或相机外参误差：前者要标定，后者见视觉坐标对齐。接触力误差则还需要合适的反馈与柔顺控制。

11. 回到位姿增量接触任务：为什么这些量影响控制选择

若策略每周期输出末端小增量，微分 IK 的 Δq=J+Δx 会放大小奇异值方向分量，导致关节速度／步长触顶；DLS 则可能主动牺牲该方向的跟踪。逐关节截断速度还可能改变末端实际运动方向。故“小增量跟不上”不一定来自低刚度或静摩擦，也可能来自运动学转换。

工程上可考虑降低目标速度、DLS、带速度／限位约束的 QP、轨迹重新定时，以及冗余姿态优化。姿态优化应尽量提前做，奇异点上缺失的一阶方向不一定能靠当前零空间梯度立即恢复。完整规划与执行链路见轨迹时标与笛卡尔运动。

对力矩型笛卡尔阻抗，映射是 τ=JTF。若任务力沿奇异方向 F=fui：

τ=fσivi.

这是乘以奇异值，不会像伪逆那样直接产生小奇异值倒数放大。但它也不保证良好接触响应：某些方向可由机构形成很强的静态支撑，同时主动退让能力退化；在理想完全奇异方向，约束反力甚至不能由关节力矩唯一推断。真实能力仍受结构承载、弹性、驱动、惯量与延迟限制，不能据此声称能输出无限接触力。

对当前任务，除了记录最小奇异值和条件数，还应看策略运动、接近及接触后退让方向在各奇异方向上的投影。同一姿态对沿面运动可能够用，对法向退让却可能很差。相关控制选择见阻抗、导纳与力位混合控制。

01 拉格朗日建模与动力学方程

创建日期：2026-11-09
最近更新：2026-11-09

本章解决什么问题

给定机器人关节状态与质量惯量，驱动机器人运动需要什么广义力？接触力、重力、摩擦和执行器力矩怎样进入方程？

快速回顾

采用独立最小坐标 q 时，刚体多关节系统常写成

M(q)q¨+C(q,q˙)q˙+g(q)+τf(q,q˙)=τ+Jc(q)Tλ.

左侧是惯性、速度耦合、重力及摩擦项，右侧是执行器广义力与接触广义力。质量矩阵 M、重力项 g 取决于质量、质心、惯量及坐标约定；写下方程不等于这些参数已经准确。

1. 广义坐标和能量

对单自由度旋转关节，q 的单位是 rad，广义力单位是 N·m；对移动关节，广义坐标为 m、广义力为 N。选坐标时须包含独立运动自由度。

拉格朗日函数为 L=T−V，其中 T 是动能，V 是势能。每个广义坐标 qi 对应欧拉－拉格朗日方程：

ddt∂L∂q˙i−∂L∂qi=Qi.

右侧 Qi 包括该坐标上的非保守广义力，如电机输入和外力的虚功映射。该方法从能量得到方程结构，不提供未知实物参数的数值。

2. 动力学各项

项 物理意义 备注
M(q)q¨ 加速各连杆所需的惯性力矩／力 M 对称；非退化机械坐标下一般正定
C(q,q˙)q˙ 科里奥利与离心效应 C 的具体表示不唯一，乘积是动力学项
g(q) 抵消重力所需的广义力 符号依方程约定；静止支撑重力时输入通常为 +g(q)
τf 传动、电机、关节摩擦等 简化项不一定足以描述低速迟滞
τ 执行器广义力 必须与关节坐标、传动映射一致
JcTλ 接触广义力 外界对机器人施力时，按本式采用正向加载约定

摩擦项可能包括黏性、库仑、Stribeck、预滑移或齿槽力矩；要按速度范围和测量条件选模型。接触力符号及接触雅可比的定义必须匹配，不能只看方程的正负号判断作用方向。

3. 单关节例子

近似水平转轴的摆臂模型可写作：

Jq¨+bq˙+mglsinq+τcsgn(q˙)=τ.

这里 J 为等效转动惯量（kg·m2），b 为黏性摩擦系数（N·m·s/rad），mgl 为重力力矩幅值（N·m）。符号取决于零位和重力方向；它是示例模型，不是所有关节的方程。

若慢速静止且无外部接触，要保持该姿态，执行器需抵消对应的重力项及静摩擦影响。实际驱动器的电流与关节力矩换算还需确认力矩常数、减速比和效率。

4. 模型用途与边界

动力学可用于前馈补偿、预测加速度、MPC、逆动力学和接触求解。参数估计与验证需另行完成，见系统辨识。几何模型正确不保证质量、摩擦或接触准确；带腱绳、弹性件或欠驱动结构时，还需加入张力、弹性形变、约束及驱动坐标映射。

02 Pinocchio 与动力学算法

创建日期：2026-11-09
最近更新：2026-11-09

本章解决什么问题

如何高效从关节状态计算机器人运动学、质量矩阵、逆动力学力矩或预测加速度？Pinocchio 是动力学模型、仿真器还是控制器？

快速回顾

Pinocchio 是基于刚体树模型的运动学与动力学计算库。它实现多体算法，但不会因为读入 URDF 就自动获得准确的实物参数，也不自动成为带接触积分的仿真引擎或电机 SDK。

1. 输入状态与算法边界

模型描述连杆质量、质心、惯性张量、关节、固定变换和限制等。调用前要确认 URDF 坐标系、关节顺序、连续关节表示、单位与根节点类型。固定基座 1-DoF 转轴的 q 常用 rad、q˙ 用 rad/s、q¨ 用 rad/s2；一般化速度空间 v 不一定和配置空间 q 同维。

广义力矩计算还依赖重力向量及外力的表达轴、施力方向和作用帧。缓存的中间计算数据必须与本次状态匹配，避免复用旧 Jacobian 或惯量结果。

2. 三个动力学递归算法

算法 已知量 求解量 常见用途
RNEA（Recursive Newton–Euler Algorithm） q,v,a 和模型 所需广义力 τ 逆动力学、重力及运动前馈
ABA（Articulated Body Algorithm） q,v,τ 和模型 广义加速度 a 前向动力学
CRBA（Composite Rigid Body Algorithm） q 和模型 关节空间质量矩阵 M(q) 控制分析、优化及方程组求解

对固定基座无外力的模型，可抽象写为：

τ=RNEA(q,v,a),a=ABA(q,v,τ).

如果向 RNEA 传入零速度、零加速度，常用于计算所需的重力补偿向量；仍须确认 Pinocchio 重力向量、力矩轴和反馈坐标一致。带外部力时，附加力项的符号由“环境施加到机器人”或“机器人施加到环境”的约定决定。

3. 为什么使用算法库

经典递归算法利用树结构重复使用子树的惯性和力递推，避免符号展开整台多体系统方程。代价通常随关节数近似线性或二次变化，具体取决于算法、模型及是否显式形成质量矩阵。

框架便于复用，也不会替用户决定 URDF 是否正确、驱动器输出是在电机轴还是关节轴、摩擦应放在哪一层，或接触约束如何求解。这些接口约定必须先验证。

4. 逆动力学、正动力学与仿真

逆动力学求执行目标或前馈补偿；正动力学预测当前力矩下的加速度。完整仿真还需要数值积分状态、碰撞几何、接触检测与求解、约束处理和执行器模型。Pinocchio 的 ABA 本身不等于含复杂接触的完整仿真环境。

工程检查可以把 RNEA 和模型预测做闭环代回，将 M(q) 用于比较，也可对 Jacobian 做有限差分核对。不过同一个模型内部互相一致，仍不代表它与硬件标定数据一致。

01 动力学回归与最小二乘

创建日期：2026-11-09
最近更新：2026-11-09

本章解决什么问题

物理动力学模型含未知参数时，怎样把数据整理成可估计的问题？为什么采很多样本仍可能无法区分两个参数？

快速回顾

先决定模型结构，再由关节状态和力矩构造回归矩阵，最后估计有限参数。线性最小二乘可高效求解，但有效结论取决于模型假设、测量和独立验证；大样本不能修复不充分的激励或系统偏差。

1. 线性参数回归

假设给定轨迹后动力学对未知参数 θ 线性：

y=Yθ+ϵ.

Y 是由输入数据构成的回归矩阵，y 是测得的广义力或力矩，ϵ 汇集噪声和模型未描述部分。用 N 个时间样本堆叠后：

θ^=argminθ‖Yθ−y‖22.

满列秩时解唯一。实际数值计算使用 QR、SVD 或成熟最小二乘库，不直接显式构造 (YTY)−1；后者会放大条件数带来的误差。

2. 最小二乘例子

对单关节简化模型：

τ=Jq¨+bq˙+γsinq+fcsgn(q˙)+ϵ,θ=[Jbγfc]T.

每个时刻提供一行 [q¨,q˙,sinq,sgn(q˙)]。这里 γ 可能是质量、重力加速度和质心长度的乘积，单凭该数据不一定能分开辨识每个物理量。

若使用权重 W，加权最小二乘为 minθ‖W1/2(Yθ−y)‖2。权重须对应已知噪声或明确的工程权衡，不应只用来“把结果调好看”。若数据存在连续采样相关性，普通独立同分布噪声的置信解释也需修正。

3. 激励与可辨识性

采样轨迹要使不同参数对应的列能被区分：

  • 只有匀速运动时，q¨≈0，惯量列缺乏激励。
  • 只在单一速度和方向运动，黏性摩擦与库仑摩擦可能高度相关。
  • 只在很小角度范围运动，重力项的变化可能与常量偏置混淆。

常用多正弦、chirp、分段速度／加速度轨迹。设计必须满足设备限位、电流／力矩、温升、速度、碰撞和人员安全边界。

SVD 可检查数据是否独立激发模型列：

Y=UΣVT,κ(Y)=σmaxσmin.

秩亏说明至少存在不可区分的参数组合；较大条件数表示在当前数据和尺度下对噪声敏感。不同物理单位会影响数值尺度，应先合理缩放列，再解读条件数。SVD 是可诊断性工具，不会自动为数据增加缺失信息。

4. 误差来源和验证

  • 对位置直接差分求速度、加速度会放大测量噪声，应考虑合适滤波或积分形式；滤波与求导也会带来延迟。
  • 电流换算力矩需要校准力矩常数和轴侧定义，电流不自动等于实测关节力矩。
  • 外部接触、温度、负载、摩擦迟滞和时间戳错位都会改变观测。
  • 训练数据拟合小，不代表新速度、反向、载荷和温度下预测仍可靠。

留出独立数据，分工况报告力矩误差、残差趋势和控制效果。若误差与速度、方向或姿态明显相关，可能是模型结构不足，而非样本太少。

02 重力与摩擦辨识

创建日期：2026-11-09
最近更新：2026-11-09

本章解决什么问题

如何估计关节保持静态所需的重力力矩？重力补偿和运动中的摩擦补偿分别对应什么数据？为何拟合一个模型不等于精确控制？

快速回顾

重力模型描述随构型变化的保守力矩；摩擦随速度、运动方向、温度和停滞状态变化。它们的辨识应匹配数据条件，并保留模型误差和偏置项。执行器命令不是传感器测得的输出，必须核对尺度并做独立测试。

1. 重力模型

忽略加速度、速度摩擦及外部接触时，静态支撑模型可写为：

τg(q)≈g(q).

具体正负号取决于动力学方程把 g(q) 放在哪一侧。串联机械臂单轴贡献常含 sinq、cosq 项；多连杆效应让多个连杆的重力矩共同映射到近端关节。利用正弦余弦线性参数化，或用已知几何模型作为基线，拟合共享的物理参数。

仅在一个姿态的测量无法验证构型变化趋势。应覆盖安全范围内具有信息量的多个姿态，并为拟合和验证留出不同姿态；也需记录末端工具、负载和安装方向。

2. 运动摩擦模型

低速近似的黏性加库仑模型：

τf=bq˙+fcsgn(q˙).

接近零速时，库仑符号函数不适合描述真实静摩擦；现实还可能有 Stribeck 效应、预滑移、迟滞和方向相关项。

要分离速度摩擦与重力，可在选定构型附近做双向、多速度安全扫描，比较同姿态不同方向／速度的读数，并检查数据随温度变化。若零速读数夹杂人手接触或传动静摩擦，就不能直接当成纯重力真值。

3. 常量偏置与重力补偿

模型可含偏置：

τmodel(q)=g^(q)+b0.

在某些数据或参数化中，重力常量项与电流偏置等常值偏置无法独立区分；预测用 g^+b0 可能可复现数据，但不能无根据分别宣称两者物理来源已确定。要进一步解释各项，需要额外校准信息或独立测量。

前馈重力补偿力矩为 τff=g^(q)（若已辨识的偏置代表同一负载来源，再按约定纳入）；它不自动构成关节位置闭环。负载改变、温度漂移、摩擦和单位尺度误差仍会造成偏差。

4. 激励、安全与验收

逐轴扫描可降低交叉运动，适用于特定受控辨识方案，但仍要限制运行范围、设置独立急停和合理的软硬限位，并确认负载支撑。不同机构和实验不应直接复制某次扫描次数或速度档位。

验收至少包括独立姿态预测误差、各轴误差分布、方向差异、重复性及负载边界。只有经过适当标定的电流才能作为力矩代理；协议中的力矩系数是否含减速比、定义在哪个轴端，需查阅厂家资料或用已知负载独立核验。

5. 典型工程数据的阅读边界

本地周报记录了一套七轴臂的正反向速度扫描、重力拟合、参数共享和真机悬停计划。这是特定机械臂、原安装及当时参数状态下的阶段记录。其数字可用于理解“独立验证、轴间差异和未完成的实机验证为何重要”，不可视为其他机器人的重力、摩擦或控制参数。尚未确认的力矩参考轴和试验结果不写成已证实结论。

03 电流—力矩映射与联合辨识

创建日期：2026-11-09
最近更新：2026-11-09

本章解决什么问题

没有关节力矩传感器，能否同时辨识电流系数与重力参数？为什么拟合很好仍不能证明绝对 N·m 正确？怎样区分命令执行链与物理力矩标定？

快速回顾

“命令值—电流”“电流—轴端力矩”“轴端力矩—机械臂运动”是不同关系。若电流系数和动力学参数同时未知，通常存在整体尺度不确定性。CAD 模型可提供锚点，但不是独立测力基准。此问题来自项目旧方案；记录其原理，不恢复已经作废的实验方案。

1. 从电机侧到关节侧，为什么不止一个系数

理想情况下，电机电磁转矩与转矩电流相关：τm=Ktiq。减速器输出侧的简化关系可写成：

τj≈ηnKtiq−τloss.

n 为减速比，η 为此工况下的有效传动效率，τloss 为所选模型中未包含的传动损失。真实损失可依方向、速度、温度与载荷变化；反向传动时不能无条件套用同一效率式。驱动器上报的“电流”还可能是相电流峰值、RMS、q 轴值或缩放后的寄存器值，必须先确认定义。

因此，一个经验 keff 常是指定工况下的等效系数，不应自动被解释为材料决定的电机 Kt，也不应在已经包含减速比的层再次乘 n。

2. 联合辨识为什么会缺少绝对尺度

考虑多姿态静态数据，写成：

Dki=Yg(q)π+b.

Dk 为未知电流—力矩系数对角矩阵，i 为电流向量，Yg 为已知几何产生的重力回归矩阵，π 为质量／一阶矩等未知参数，b 为力矩侧偏置。这里暂略静摩擦与外部接触，只用来说明可辨识性。

若 (Dk,π,b) 能解释数据，则对任意正数 c，(cDk,cπ,cb) 也能解释同一数据：

cDki=Yg(q)(cπ)+cb.

仅靠这些平衡关系无法选出绝对尺度。直接求这种齐次残差还可能得到全零解；增加更多相同类型姿态，不能自动消除结构性尺度自由度。模型可能另有参数耦合，本式只证明至少存在这一个歧义。

固定一个质量／一阶矩、已知可信的电流系数，或加入独立标定载荷，可提供额外信息。用 URDF/CAD 提供锚点能得到有用的模型尺度，但结果仍继承该锚点误差。只有把信息来源和不确定度写清，才能解释拟合结果。

3. 命令回读不是独立的力矩测量

假设某固件按局部线性映射把协议力矩命令转换为目标电流：

icmd=uτkfw.

这只是说明用的模型，不代表已掌握当前固件实现。若“力矩反馈”又由同一 kfw 乘实测电流得到，它可以反映电流执行情况，却没有独立证明实际关节力矩等于命令 N·m。

项目历史讨论中，厂商 xcore 接口从 N·m 指令与反馈开始，而自研 CAN 链路还需要核对寄存器尺度和轴侧。不能因为两个 API 都叫 torque，就认为底层传感来源、内部补偿与标定边界一样。未公开的厂商内部算法不作推断。

4. 验证链应分成哪些层

验证层 要回答的问题 合适证据
协议与执行 正负命令是否产生相应电流，增益和延迟如何 指令、电流、时间戳与模式回读；位移应高于噪声底才可用于方向判断
模型预测 多姿态下需要的补偿电流能否被预测 未参与拟合的姿态／方向／负载、重复采样
绝对标定 已知物理力矩对应多少电流 已知力与力臂、标定过的力／力矩传感器；扣除其他负载和偏置
控制效果 在所需工作范围能否稳定、可重复地执行 实际漂移、误差、饱和、温升与扰动恢复记录

已知力参考可用 τ=r×F，但测的是哪一轴、力臂方向、机器人自重和夹具载荷都要进入账目。拟合图上的低残差不能代替这些检查。

5. 为什么项目没有必要一直升级联合模型

历史联合方案后来已被逐关节、分方向采样与重力／等效摩擦分析替代。本章保留的是“为何绝对尺度不足”“如何解释反馈”，不把旧参数文件或旧拟合结果重新标为有效。

逐关节方案易观察、便于诊断，但其他关节固定并不使整机动力学在物理上完全解耦；单轴拟合的有效范围仍依赖其余关节姿态。末端轻关节信号弱时，增加未知参数可能进一步恶化条件数。

工程上常按已有传感条件分层处理：有可信力矩反馈时辨识负载和动力学；只有电流时明确代理测量和标度；需声明绝对 N·m 精度时引入独立参考。这是模型与证据的匹配原则，不是声称所有厂商使用同一标定算法。

01 约束优化与问题分类

创建日期：2026-11-09
最近更新：2026-11-09

本章解决什么问题

如何把机器人任务写成优化问题？QP、SOCP、NLP、SQP 分别表达什么数学结构？何时使用自动微分？

快速回顾

先确定变量 z，再说明目标 f(z)、等式约束 h(z)=0 和不等式约束 g(z)≤0。算法类别由问题结构决定；“用了高级求解器”不能弥补目标量纲、坐标或硬约束建模错误。

minzf(z)s.t.h(z)=0,g(z)≤0.

1. 变量、目标与约束

规划机械臂动作时，z 可以是关节位置、轨迹结点、接触点或力。目标表示在可行解之间更偏好的选择，例如路径短、动作平滑、能耗代理小或接近期望姿态。约束表示不能违反的条件，例如关节限制、动力学、力矩范围和无碰撞间隙。

软目标可用代价权重表达，硬安全限制应使用真正的约束或保护层。若软约束违约会导致硬件损坏，只用小权重惩罚无法保证安全。

不同单位的量直接相加会造成尺度偏置。应定义归一化或物理上有意义的权重，并查看单项值和梯度量级，而非仅报告一个总 cost。

2. 常见问题类型

类别 数学特征 典型任务 需要检查
LS／WLS 最小化线性残差的平方 系统辨识、局部位姿求解 秩、权重、测量噪声
QP 二次目标、线性等式与不等式约束 速度 IK、WBC 子问题 凸性、可行性和实时预算
SOCP 凸二次／线性项与二阶锥 具凸摩擦锥的力分配 摩擦锥近似与变量标定
NLP 一般非线性目标或约束 轨迹、接触点联合优化 局部解、初值、梯度和尺度
SQP 迭代线性化约束、二次近似代价 平滑 NLP、受限轨迹优化 收敛区域、子问题耗时、线搜索

SLSQP 是一种带约束的序列二次规划求解实现。求解器返回成功标志仍要检查原始约束残差、时间预算和独立的执行安全。

3. 接触与互补约束

法向接触可用间隙 ϕ(q)≥0 和法向力 λn≥0 表示不穿透与不能拉住的单边接触。刚体接触的理想互补关系：

0≤ϕ(q)⟂λn≥0,ϕ(q)λn=0.

物体分离时允许有间隙而没有接触力；接触时可有法向力而间隙为零。互补约束非线性且非凸，对接触建立／分离切换不光滑。用罚函数软化可能引入穿透或数值刚度；使用接触隐式优化则需评估求解器与任务规模。

库仑摩擦锥约束涉及切向力范数。精确二阶锥建模有时可转为 SOCP；多接触模式切换和与关节动力学联合优化仍可能为非凸问题。

4. 梯度与自动微分

梯度来源包括解析推导、自动微分和有限差分：

  • 解析梯度快且精确，但推导和代码维护成本高。
  • 自动微分可沿可微计算图求导，精度通常好于有限差分；硬碰撞、离散接触或外部不可微算子仍有限制。
  • 有限差分适合校验小问题，但步长敏感、容易受噪声影响，高维函数调用代价大。

若使用数值梯度，至少用方向有限差分在代表状态核对梯度实现。无论方法为何，都要验证导数所对应的计算路径与真实执行模型一致。

5. 求解质量与诊断

解慢时依次记录变量维数、每次目标／约束耗时、碰撞对数量、导数耗时和迭代数。可改善初值、使用结构稀疏性、减小不必要自由度、对距离查询加空间筛选，并独立验证路径结点之间的安全性。

连续碰撞不等于“所有离散结点无碰撞”。结点间仍可能穿过障碍，应加密验证、保守间距或连续碰撞检测。

6. 正则项表达什么，为什么不能代替硬约束

正则化（Regularization）把偏好加入目标：

minz Ltask(z)+λR(z),λ≥0.

Ltask 衡量主要任务误差，R 惩罚不希望的结构，λ 决定取舍。机器学习中的参数范数正则可限制复杂度；机器人控制中，同样的形式可表达动作平滑、少动关节或接近参考姿态，不能把所有正则都只解释成“防过拟合”。

项目情形 可选正则项 意义与代价
七轴 IK ‖q−qref‖2 偏好参考姿态，可能牺牲部分位姿误差；关节 bounds 仍独立存在
局部反解 ‖Δq‖2 抑制奇异方向的大步长，即 DLS 的关键作用
离散动作序列 ∑k‖uk−uk−1‖2 抑制指令跳变，可能减慢接触切换
辨识 ‖θ−θ0‖2 向先验收缩，减小病态放大，同时引入先验偏差

DLS 的 λ2‖Δq‖2 是惩罚本次增量，不等于每次都把绝对关节角拉向零位。持续姿态偏好需要显式的 qref 或次任务设计。

增大权重能改变最优解，却不保证关节速度或碰撞距离永不违规。例如动作差分代价即使很大，也可能为了降低任务误差接受一次较大的变化；若变化率有硬上限，应显式加入 |uk−uk−1|≤u˙maxΔt，再检查执行端约束。

7. 为什么“加权平滑”和“改变控制动态”要分开看

在 PPO 奖励里惩罚动作差分，是训练策略在任务收益和平滑之间选择；部署时对动作做 EMA，是在策略外改变实际执行动态。二者可能同时使用，但不等价。后加滤波产生策略未见过的延迟，应回到仿真和目标分布验证。

在 IK 中，多目标加权和便于快速实现，但权重变化可能让主任务和姿态偏好互相妥协。若主次层级严格，应考虑分层优化／显式约束，同时核对可行性与实时预算。具体项目中没有证据支持“一律换成更复杂求解器”；先看真正需要保持的是硬限制、任务层级还是软偏好。

01 RRT、碰撞检测与轨迹优化

创建日期：2026-11-09
最近更新：2026-11-09

本章解决什么问题

复杂障碍场景中怎样找到避障路径？随机采样的 RRT 和数值轨迹优化怎样互相补充？离散无碰撞检查意味着什么？

快速回顾

逆运动学找一个构型；路径规划在配置空间找几何路线；轨迹规划再为运动分配时间、速度与加速度。RRT 有助于探索复杂非凸可行空间，局部优化能平滑或降低代价，但依赖初值，最终必须独立碰撞验证。

1. 三个不同层次

  • 逆运动学（IK）：由末端目标找一个满足运动学方程的关节状态。
  • 路径（Path）：描述从起始配置到目标配置的几何曲线，尚不一定有时间参数。
  • 轨迹（Trajectory）：给路径附加时间，确定 q(t),q˙(t),q¨(t)，以便检查执行约束。

找到终点 IK 不等于中间有可行路线；几何路径可行也不等于驱动器能按指定时间执行。

2. RRT 与局部优化

快速探索随机树（Rapidly-exploring Random Tree，RRT）在配置空间采样，并将样点接入已建立的树。它可探索障碍导致的非凸区域，但基础 RRT 给出的路径可能折线冗余、靠近障碍且不平滑；RRT* 的渐近最优性需要相应假设和充分计算，有限运行不保证全局最优。

实用组合示意：

起点、目标和场景 -> RRT 或多初值采样 -> 可行路径
                  -> 插值与时间离散 -> 轨迹局部优化
                  -> 加密碰撞验证 -> 时间参数化与执行器检查

优化代价可以包含路程、平滑、关节姿态或障碍间隙，受关节限位、碰撞、起终端和动力学限制约束。选定每一项要定义单位、权重和硬／软边界。

3. 碰撞距离和连续验证

场景可使用几何体、网格或距离场（例如 ESDF，Euclidean Signed Distance Field）。若 d(q) 是机器人到障碍物的距离，一个软代价可惩罚 max(0,dsafe−d(q))2；硬约束可规定 d(q)≥dsafe。软罚项并不能保证安全阈值不被违反。

用有限采样点检查机器人几何，只能保证采样时刻不碰撞。结点之间仍可能发生碰撞，细长机械结构、快速动作和柔性机构尤其需要更密或连续检测。距离场精度、网格近似和安全余量也要核验。

4. 从规划到真实执行

轨迹最终需满足电机可用速度、加速度、力矩、周期和 SDK 限速；路径末端线段插值还要先通过逆运动学，关节空间的限速可能使实际笛卡尔路径弯曲。仅对理想位姿插值计算路径偏差，会漏掉关节插值后 FK 得到的真实末端偏差。

本地 SDK 位控审查曾记录实际设备限速回读与轨迹证据校核。这类结果说明路径算法与驱动器接口校验属于完整执行链的一部分，而不是 RRT 的属性。

02 轨迹时标与笛卡尔直线运动

创建日期：2026-11-09
最近更新：2026-11-11

本章解决什么问题

IK 在只要求终点、要求完整笛卡尔路径和每周期位姿增量控制中分别放在哪里？路径如何转换为可执行速度曲线？怎样保持末端路径，同时尊重关节限速和加速度？

快速回顾

IK 寻找可实现目标的关节构型，路径决定中间怎么走，时标决定何时到哪里。终点有 IK 解不能代替整条路径验证，直接笛卡尔阻抗也不一定需要目标关节 IK。单轴梯形规划把速度分为加速、匀速和减速段；多轴同步要协调各轴时间。关节限速下的笛卡尔目标不能只在线性插值后直接假定真实机械臂仍走直线。

1. 梯形速度规划

规划输入包括当前位置、目标位置、初始／目标速度、速度上限和加速度上限。采用常加速度时：

q(t)=q0+q˙0t+12at2,q˙(t)=q˙0+at.

若行程足够，速度曲线呈“加速—匀速—减速”；短行程可能达不到速度上限，退化为三角速度曲线。初始速度已经超过新设限速时，先按正时间规划减速，不应生成负时长加速段。

若允许加速度不连续，有限加速度曲线仍会产生加加速度（jerk）突变。对脆弱物体或高端执行器，需另用 jerk 限制的 S 曲线或适当平滑。

2. 多关节同步

为使多轴同时完成同一个动作，可先分别规划各轴最短合法时间，再以最长时间作为同步时长，重新分配各轴峰值速度／加速度。任何缩放后方案都要重新检查驱动器的实际限速和加速度上限。

连续段拼接还需要检查段间位置、速度、加速度连续性。只验证最终位置窗口不代表整段轨迹速度合规。

3. IK 在规划中的两种用法

3.1 只要求末端终点：先生成目标构型候选

例如夹爪需要到达物体上方，中间不规定必须走直线。典型流程是：

末端目标位姿 → IK 候选构型 → 限位／终点碰撞检查 → 关节空间路径规划 → 时间参数化 → 执行检查。

IK 回答“终点有哪些关节姿态”，规划器回答“从当前姿态怎样走过去”。一个目标可能有多个 IK 分支：最近的分支可能路径受阻，另一个分支反而更容易到达。可以保留多个候选供规划比较，而不是只取第一次返回的解。

对于要求较复杂的任务，也可把终点解和路径联合优化；上面的分层流程是解释职责的常见结构，不是唯一实现。具体 IK 的解析与数值方法见SVD 与逆运动学。

3.2 规定末端沿途路径：连续寻找整条关节路径

直线接近、沿面移动等任务需要先给出末端路径，再寻找连续的关节解。相邻末端目标接近，不代表独立选出的关节解也接近；从肘上解跳到肘下解，会造成大的关节变化。

数值 IK 可用上一个有效解作初值；解析 IK 可枚举候选并选择连续分支。还要结合实测关节位置，检查关节限位、碰撞、奇异性和速度能力。贪心选最近解不保证整条路径成功，必要时需回溯、换分支或联合优化。

端点都有解，也不代表存在满足指定末端路径的连续关节路径。两端关节角线性插值，末端通常也不走直线。因此必须核验路径中间，而不仅是端点。

4. 笛卡尔直线、连续 IK 与时标

平移路径可按路径进度 s(t) 插值：

p(t)=p0+s(t)(p1−p0),0≤s(t)≤1.

姿态另用声明明确的旋转插值，例如四元数 SLERP。沿路点求逆运动学后，还需连续选择解支路、满足关节速度／加速度限制，并用真实关节路点 FK 复算误差和碰撞。

逆运动学失败、靠近奇异位形或单轴限速时，可能无法维持要求的路径和时长；算法应明确报告失败或重新定时，不能静默超速。

5. 每周期位姿增量：规划与控制的边界

当前讨论项目由策略输出末端位姿增量，底层控制器可修改。这是每周期更新局部目标的控制链，不必每次重新运行完整的全局路径规划，但仍需维护参考连续性和可执行性。

底层结构 位姿增量之后的典型链路 IK 的位置
位置控制 更新末端参考 → IK／微分 IK → 关节运动目标 → 关节伺服 将参考运动转为关节运动
导纳＋位置控制 更新名义参考 → 外力生成修正 → 修正位姿 → IK／微分 IK → 关节伺服 作用于导纳修正后的参考
直接笛卡尔阻抗 更新参考 → 与实际位姿比较 → 恢复 Wrench → Jacobian 转置 → 关节力矩 不必先求目标关节配置，但仍需 FK、Jacobian 与限位／构型管理

微分 IK 用局部关系 Δx≈JΔq 生成小步关节变化；其姿态增量是局部小转角，不能把任意大的位姿差直接当作线性量。需处理尺度、奇异性、步长和关节限速，执行后用实际状态闭环修正。

各环节失败时的行为应明确：目标投影、限速或 DLS 会改变策略实际得到的运动，不能静默假装完全执行。若在关节空间逐轴截断速度，末端运动方向也可能偏离要求；可以考虑整体时间缩放或带约束的运动学优化，但都需重新检查可行性。

接触任务还应区分规划的名义几何路径和柔顺后真实路径：允许法向退让，并不代表切向精度要求也可以放弃；固定几何路径满足位置要求，也不等于满足接触力要求。控制选择见阻抗、导纳与力位混合控制。

6. 反馈接口与停止

规划依赖执行器实际限速和当前状态，不能只相信缓存配置；超时后旧目标仍可能有效，因此停止策略还需撤销命令并确认设备状态。通信轮询、控制周期和物理时标也要分别说明。

01 相机标定与仿真坐标对齐

创建日期：2026-11-09
最近更新：2026-11-09

本章解决什么问题

内参、外参、手眼标定各解决什么？拧盖论文把 marker 放进仿真，究竟省掉了哪一步？为什么标定误差小仍不等于物体定位可用？

快速回顾

内参描述三维相机坐标到像素的投影，外参连接坐标系，手眼标定利用机器人运动求固定相对变换。仿真中的 marker 可提供已知世界坐标，但仿真与实物之间的几何关系仍要真实建立，不能凭空消除测量误差。

1. 三类标定不要混在一起

忽略畸变的针孔模型为：

zc[uv1]=K[xcyczc].

K 为内参矩阵，u,v 为像素，xc,yc,zc 为相机坐标；畸变需要额外模型。深度相机还要确认深度单位、RGB／Depth 对齐和内参对应的分辨率。

沿用 TAB 把 B 系坐标变到 A 系的约定，外参关系为：

pW=RWCpC+tWC.

内参正确并不意味着已知 TWC；外参正确也不能修正错误的深度尺度。

方法／目标 输入 解决什么 适用条件
多视角棋盘格／标记板内参标定 板上已知点与多张像素观测 内参、畸变及各图相对板位姿 覆盖视野、距离和倾角，避免只拍几乎相同姿态
PnP 已知三维点、二维像素、内参 目标相对相机的位姿 通常不依赖深度图；要处理平面歧义和坏点
三维刚体配准 相机系与世界系的三维对应点 RWC,tWC 两套坐标量纲一致，点集有足够几何跨度
手眼标定 多组机器人与标记物观测运动 相机与末端／基座的固定变换 明确 eye-in-hand 或 eye-to-hand 安装及运动约定

PnP 的输出常是世界／物体系到相机的方向，使用前需核对是否要取逆；不要直接靠矩阵变量名猜方向。

2. 对应点如何解刚体变换

若已经得到三维对应点，可求：

minR,t∑iwi‖piW−(RpiC+t)‖22,RTR=I,detR=1.

先减去两组点的加权质心，再用互协方差矩阵的 SVD 求旋转、处理行列式符号，最后恢复平移。至少需要非共线且分布合理的对应点；重复读取几乎同一位置不能替代几何激励。深度噪声、角点错误或 marker 尺寸不准会进入估计，必要时做异常值剔除和多次观测。

若没有可靠三维相机点，却有二维角点和内参，则应考虑 PnP，而不是把像素直接当作米制三维点送进配准。

3. 手眼标定为什么是另一种问题

当相机固定在机械臂末端时，不同机械臂运动和标记物观测可给出相对运动关系：

AiX=XBi.

X 是待求的固定安装变换，Ai,Bi 是在选定约定下对应的两组相对运动。必须说明运动方向与坐标系；eye-to-hand 的链式关系与数据准备不能直接照搬 eye-in-hand。

多方向旋转与足够位移提供可辨识信息；只做近似同轴或纯平移运动可能导致退化。OpenCV 的标定接口提供多种经典求解方法，但调用同一 API 不会自动消除输入方向、机器人零位或时间同步误差。

4. 拧盖论文究竟做了什么

本轮重新查阅 Twisting Lids Off with Two Hands 的本地 v2 PDF 第 8 节：作者在仿真中加入真实系统使用的 marker，使 marker 角点能在相机与世界坐标中形成对应关系，再求相机外参。论文把减少人工拍棋盘格及求多级外参的工作作为优点。

它没有在这一段给出完整内参标定、RGB—Depth 对齐或具体外参求解器，也没有报告该流程的定量标定误差。因此不能把上述 SVD 配准说成作者明确使用的算法，或宣称论文证明它比棋盘格更精确。本章把三维配准作为可选实现原理，和论文明确陈述区分开。

关键前提是：真实 marker 相对任务世界的位姿，与仿真中设定的关系一致。仿真提供的是你输入的几何，不会自动测出真实安装误差。

5. 联系 L20 双手拧盖，怎样选一条可落地路线

若相机固定、主要需要瓶身／瓶盖在任务坐标中的位置，可先复用经核验的相机内参与深度对齐，再通过已知 marker 建立相机—任务世界变换；只在需要时引入额外的机器人基座链。若相机装在末端，或任务要跨机械臂运动维持标定关系，再考虑手眼流程。

比较 PnP 与 RGB-D 三维配准时：前者依赖角点、内参和目标几何，后者还受深度噪声和对齐误差影响；实际可按工作距离、遮挡和传感质量做独立测试。固定标记物、棋盘格／标记板、PnP 与手眼求解都是成熟工具链中的常见构件，选用取决于安装关系，不存在一套步骤适用于所有相机。

验收不只看参与拟合的角点残差。还应在操作空间内用未参与拟合的位置检查误差，分别观察瓶身和瓶盖，记录遮挡、缺测与观测延迟。相机静态很准但延迟过大，策略仍可能对旧位置做动作；这与训练期的噪声／延迟模型必须一起考虑。

跨设备维护与阅读说明

创建日期：2026-11-09
最近更新：2026-11-09
来源：本次讨论整理、本工作区的 Markdown 与阅读版生成工具，以及文末实际查阅的 GitHub 官方文档。

1. 当前方案与目标

笔记需要在不同电脑上持续维护，也希望能够通过手机浏览、修改 Markdown 和上传技术资料。用户选择使用 GitHub 管理现有笔记，以减少服务器成本，并明确要求废弃此前的独立网站和手机界面方案。相关应用、界面、测试、截图和部署配置已删除，后续以 Markdown 和 GitHub 为维护方式。

仓库为 Lucute7/lkw-technical-notes，已通过认证查询确认是私有仓库。本地 Git 仓库已初始化并关联该地址，GitHub CLI 已安装，用户已完成浏览器授权。是否已取得最新内容，应通过远端版本核对，而不能仅凭本地保存或收到链接判断。

内容源是 Markdown；阅读版.html 是由本地工具生成的离线阅读产物。GitHub 保存已经推送的共享版本，各电脑取得同一套文件后继续维护。

2. 笔记、资料和聊天记录的区别

数据 用途 GitHub 维护方式
已整理笔记 长期复习的主题章节、公式、自测与结论 Markdown、分类目录和复习清单一起提交
技术资料 PDF、图片、手册和示例等原始材料 小型文件放在相关分类的 assets/ 或 examples/，从章节链接
本地聊天记录 推理过程、尚未解决的问题和原始交流 不会自动同步其他电脑的聊天；需要将已明确结论和待讨论问题整理到笔记

仓库中的笔记、未解决问题和 AGENTS.md 为不同电脑上的助手提供共同上下文。另一台电脑取得最新文件后，可以基于笔记继续讨论，不必依赖完整的原始聊天历史。

上传手册不等于已经阅读或理解其中的内容。当前没有自动 OCR、资料抽取或自动问答；笔记只记录实际讨论和实际查阅过的材料。

3. 费用与权限

GitHub Free 个人方案提供不限数量的私有仓库（Private Repository），基本文本维护通常无需额外付费，不要求租服务器。本项目已确认使用私有仓库，通过 GitHub 账号控制访问。

GitHub Actions、Codespaces、Git LFS 等附加功能有各自额度和计费规则，不能把“基本仓库免费”扩展为所有服务和任意文件量都永久免费。当前基本维护流程不要求启用这些附加功能。

4. 创建仓库与首次接入

新建空仓库的方法

以下作为未来创建其他笔记库的操作参考。本项目已完成创建，首次接入时通过认证查询确认是私有空仓库。

  1. 登录 GitHub，打开新建仓库页面，或点击右上角“＋”并选择 New repository。
  2. Owner 选择个人账号，Repository name 填写仓库名，例如 technical-notes；示例名称不代表本项目实际仓库名。Description 可填“个人技术笔记”或留空。
  3. 可见性选择 Private，用于限制内容访问。
  4. 已有本地笔记时，不预先添加 README、.gitignore 和 License，以创建空仓库。本地已有的目录与忽略规则可在首次上传时一并提交。
  5. 点击 Create repository。看到快速设置或命令行示例页面，说明空仓库已经创建。
  6. 复制地址栏中的仓库链接，格式为 https://github.com/账号名/仓库名，供本地关联使用。

首次接入需要确认什么

创建远端仓库只准备了保存位置，本地文件尚未上传。接入时先检查远端默认分支和已有内容，再初始化或克隆本地仓库、配置认证、提交并推送。远端已有文件时要保留并合理合并，不直接覆盖。

浏览器已登录 GitHub，不代表终端中的 Git 已具备访问私有仓库的权限。仓库链接用于定位仓库；实际读取和推送仍需要本机完成 GitHub 认证。不要把密码或访问令牌写进笔记或远端 URL。

本机已通过 GitHub CLI 完成浏览器设备授权：命令行申请一次性代码，用户在 GitHub 官方授权页面登录并确认，工具在本机保存登录状态。一次性授权码不属于知识笔记，不应提交到仓库。当前提交身份使用账号名 Lucute7 及 GitHub 提供的 noreply 邮箱，不公开个人邮箱。

5. 不同电脑的日常维护流程

  1. 完成首次上传后，在另一台电脑克隆（Clone）同一仓库；每台电脑首次执行一次。
  2. 每次开始维护前拉取（Pull）最新内容，再打开该仓库工作区讨论或编辑。有未处理的本地改动时，先保留这些改动再同步。
  3. 修改章节、分类目录与复习清单，按主题重组内容，并检查受影响的旧结论和内部链接。
  4. 运行 python3 tools/build_reader.py 重新生成阅读版。构建需要 Python 3.10+、Node.js 和仓库内的离线依赖；详见阅读版生成工具。
  5. 检查差异，提交（Commit）并推送（Push）至 GitHub。
  6. 其他设备再次拉取，或刷新 GitHub 页面，读取最新已推送内容。

本地保存、提交、推送是三个不同动作。提交只记录在当前电脑，推送成功后其他设备才能从 GitHub 取得更新。可以使用 GitHub Desktop 完成常见同步操作，减少命令行操作。

6. 浏览器与手机阅读、编辑

登录有仓库访问权限的 GitHub 账号，可以在网页中阅读排版后的 Markdown、编辑文件并提交、上传资料。GitHub Markdown 支持数学表达式。手机浏览器也能使用这些功能，但长篇编辑的便利程度取决于屏幕和浏览器体验。

阅读版.html 在仓库预览中通常显示源码，不会像普通网页那样直接运行。需要完整离线阅读版时，下载后用支持 MathML 的浏览器打开；手机日常阅读优先使用 GitHub 的 Markdown 预览。

GitHub 网页直接修改 Markdown 后，已提交的 HTML 不会自动重新生成。需要在有构建环境的电脑上拉取、生成阅读版并推送；如有需要，可另行配置自动构建。目前没有配置自动构建。

7. 资料大小、修改冲突与备份

小型 PDF、图片和示例材料可以存入仓库并在章节中引用。GitHub 网页上传单个文件上限为 25 MiB，普通 Git 仓库阻止大于 100 MiB 的文件。大量大文件不适合直接放进 Git 历史，应另外选择资料存储方式。

两台电脑都从同一个旧版本开始修改，可能在同步时产生冲突。Git 能记录文件变化，但不能自动理解并合并相互矛盾的技术结论。需要检查双方内容、保留有效知识并解决冲突，不使用强制推送来跳过内容核对。

版本历史有助于追溯，但不替代独立备份。保留本地副本，并根据需要另存完整笔记目录。未推送内容还不在 GitHub 上；存在于未提交文件中的修改也不在 Git 历史中。

8. 维护要点与常见问题

  • 当前以 Markdown 和 GitHub 维护，独立网站与手机界面方案已废弃并删除相关文件。
  • GitHub 保存已经推送的共享版本；每次先同步，修改后提交并推送。
  • 不同电脑共享的是整理后的笔记，不会自动共享完整聊天记录。
  • GitHub 页面可直接阅读和修改 Markdown；离线阅读版需要构建并下载后打开。
  • 基本私有仓库维护可免费使用，大文件和附加服务另有规则。

常见问题：

  1. 本地保存、提交和推送分别改变了哪里？为什么提交之后还需要推送？
  2. 浏览器已经登录，为什么终端访问私有仓库还可能需要认证？
  3. 两台电脑分别修改同一份笔记后，怎样避免覆盖有效内容？
  4. 网页修改 Markdown 后，为什么离线阅读版还可能是旧版本？
  5. 上传一份手册，为什么不能等同于已经整理其中的技术结论？
