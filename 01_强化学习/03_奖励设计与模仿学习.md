# 03 奖励设计与模仿学习

创建日期：2026-11-09  
最近更新：2026-11-09

## 本章解决什么问题

策略的真实任务目标与训练奖励如何对应？为什么额外惩罚有时会抑制所需行为？Teacher–Student、DAgger、RMA 和历史编码各解决哪种问题？

## 快速回顾

奖励应促进可验证的任务行为，不要让代理奖励取代真实成功定义。模仿学习用专家行为提供监督；DAgger 在 student 自己访问的状态上追加专家标签；历史编码和 RMA 则尝试从时间序列推断未显式观测的环境或动力学变化。

## 1. 奖励不是目标本身

奖励函数是优化对象的代理。设计时逐项明确原始量纲、正负方向、计算频率、门控条件、终止判据和每回合累计范围。奖励曲线提高只说明算法找到了高奖励行为，不自动说明任务成功。

在灵巧手抓取后旋转物体的任务中，可分阶段考察接近、建立稳定接触、实现目标旋转和维持抓取。若要求物体从不短暂失去任何接触，奖励可能阻断必要的 finger gaiting（手指交替释放并重建接触）。是否惩罚脱离，要结合任务是否需要重新换指判断。

排查奖励投机时，同时检查策略行为和独立物理事实：接触几何、穿透、位移、载荷、成功条件和异常终止。给奖励逐项作消融实验，通常比只看一个加权和更容易定位问题。

## 2. Teacher–Student 与 DAgger

Teacher–Student 训练让较强 teacher 基于仿真真值或特权状态产生动作，再教 student 从部署可得的传感输入学习。student 模仿得到的动作不一定满足安全限制，最终还须通过闭环评价。

行为克隆（Behavior Cloning，BC）将既有专家轨迹作为监督样本。但 student 一旦偏离专家轨迹，未来状态分布也可能偏离训练集，错误会逐步累积。

DAgger（Dataset Aggregation）迭代如下：

```text
student 执行 → 收集 student 访问状态 → 专家标注这些状态
            → 追加数据集 → 重新训练 student
```

这样补充了 student 真正会遇到的分布，但依赖能够查询专家的标签、可靠安全采集和明确的数据混合规则。

## 3. RMA 与历史观测编码

Rapid Motor Adaptation（RMA）类架构使用一段短历史观测与动作，编码出当前任务状态没有直接提供的环境动力学特征，例如载荷、摩擦变化的代理表示。根据预测出的潜变量条件化控制策略，使其适应变化。

历史编码并不能保证潜变量等于某个真实物理参数；输入需包含对变化有信息的动态响应、时间戳和足够探索。若场景里执行器未激发负载差异，模型无法仅凭历史推断未观测量。

历史 encoder 可用重建或 teacher 特权量作为辅助监督，但要保持部署 Actor 的原始可观测边界。旧会话中的 RMA 配置示例属于讨论快照，不视为当前项目的实时实现。

## 4. 域随机化与课程学习

域随机化在仿真训练中对有现实依据的摩擦、质量、延迟、偏差和传感噪声等因素采样，扩大策略遇到的条件分布。随机化不是“越多越好”：范围过宽会增加与任务无关的难度，欠缺真实数据时任意范围也无法保证迁移。

课程学习逐渐调整初态或任务难度，以改善学习过程。课程定义应规定阶段指标、推进阈值、回退条件和各阶段独立评估；不能因为固定初态成功就假定带定位误差后也能成功。

## 自测题

1. 为什么回合回报增加不等于真实任务完成？
2. 某些手指短暂脱离为何可能是必要动作？
3. DAgger 怎样处理 student 自身访问的状态分布？
4. RMA 隐变量能否直接解释成物理参数？需要哪些信息？
5. 域随机化的现实范围从哪里获得？
