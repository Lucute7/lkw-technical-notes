# 03 PMSM 与 FOC

创建日期：2026-11-09\
最近更新：2026-11-09

## 本章解决什么问题

永磁同步电机（PMSM）的三相电流如何参与产生转矩？磁场定向控制（Field-Oriented Control，FOC）为什么需要 Clarke 与 Park 变换？

## 快速回顾

FOC 根据转子电角度把三相电流映射到旋转的 d/q 坐标系，以近似独立调节磁链相关分量和转矩相关分量。q 轴电流和电机电磁力矩相关；它不是关节输出力矩传感器，也不说明驱动器的电流定义或轴侧换算。

## 1. 主要控制链

典型电流 FOC 闭环如下：

```text
采样相电流 ia、ib、ic 与电角度 theta_e
    -> Clarke：静止坐标系 i_alpha、i_beta
    -> Park：旋转坐标系 i_d、i_q
    -> d/q 电流 PI 与电压／电流限制
    -> 逆 Park 与 SVPWM 生成逆变器开关信号
    -> PMSM 与电流采样反馈
```

实际实现可能使用两电流采样、不同 PWM 调制、采样补偿、反电势前馈或电流解耦；上图只是基本概念链。

## 2. 坐标变换的意义

Clarke 变换把三相量映射到静止两轴平面；平衡三相且无零序分量时，两维足以表示平面磁场。Park 变换再绕转子磁链同步旋转，使随电角度变化的交流分量在稳态时近似为直流量，PI 控制器更易处理。

工程公式需明确 Clarke 的幅值不变还是功率不变归一化，d/q 轴方向，电角与机械角的关系，以及电流峰值还是 RMS。不同约定会改变换算系数，不能只复制一种符号表。

## 3. 电流与电磁转矩

表贴式永磁同步电机、采用常见峰值相电流与相应 Park 约定时，电磁转矩简化为：

$$
\tau_e\approx\frac{3}{2}p\psi_f i_q.
$$

$`p`$ 是极对数，$`\psi_f`$ 是永磁磁链，$`i_q`$ 是 q 轴电流。符号和常数因坐标与电流归一化而异。凸极内嵌式 PMSM 还含 $`i_d`$ 和 d/q 电感差产生的磁阻转矩项。

因此常见 $`\tau_e\approx K_t i_q`$ 是已吸收到所选约定中的工程写法。电机电磁转矩经过转子惯量、轴承、减速器、效率和摩擦后，才与关节输出转矩相关。

## 4. PI 与 SVPWM

d/q 轴电流控制器比较实测电流和目标电流，PI 产生电压命令。电机绕组电感和电阻决定电流响应；电压受直流母线和调制饱和限制，目标电流可能无法达到。SVPWM（Space Vector Pulse Width Modulation）依据所需电压矢量选择逆变器开关占空比，受母线电压与扇区线性范围约束。

电流模式仍是反馈控制，只是闭环主要控制 q 轴／电流。上层若需要位置或速度跟踪，还需另加外环或使用驱动器提供的更高层模式。
