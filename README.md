## 如何积累

- 在这个工作区中讨论技术问题时，默认把有实质内容的讨论整理进相应章节，并在回复中简要说明更新位置。
- 同一主题持续补充同一章节；内容较多、主题可以独立复习时，再拆成新章节并添加关联链接。
- 讨论可以跳跃，也可以回到旧主题。笔记按知识结构持续修订：新内容放回对应位置，必要时重组章节，并同步修正受影响的旧解释、公式、例子和自测题。
- 章节围绕“问题是什么 → 为什么这样做 → 原理与推导 → 例子与应用 → 易错点 → 自测题”展开，按实际内容取舍。
- 区分已有结论、依赖条件、个人经验和待验证问题；讨论尚未明确的地方保留疑问，不写成定论。
- 发现旧结论有误时修正正文；影响理解的重要修正，在章节更新记录中说明。
- 公式默认以排版后的数学表达式呈现；程序代码仅用于实际实现示例。章节更新后同步生成阅读版。

## 如何复习

1. 从[复习清单](复习清单.md)选一个主题，先不看正文回答自测题。
2. 阅读章节中的“快速回顾”，再针对薄弱处重看推导和例子。
3. 把仍不理解的问题带回讨论，继续补充原章节。

章节使用[技术章节模板](模板/技术章节模板.md)作为参考，不要求每一章机械填满所有栏目。
