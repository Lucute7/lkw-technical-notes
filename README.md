## 如何积累

- 有实质内容的讨论按主题整理，优先修改现有章节；讨论可以跳跃，结构不按聊天顺序堆积。
- 原理解释应回答问题背景、符号与前提。重点主题可进一步说明为什么这样选、替代方法、项目应用与验证方式，不要求每个知识点都机械扩写。
- 工程或学术实践以具体资料、公开实现和任务条件为依据；不把一个开源示例说成全行业统一方案。
- 历史项目记录保留时间和状态，已经作废的方案可用于解释误区，不能重新当作当前实现。新增分析与历史已讨论结论分别说明。
- 修改结论时回查相关公式、例子、自测和链接；读者不应看到相互矛盾的有效结论。
- Markdown 是内容源；章节和导航更新后运行 `python3 tools/build_reader.py`，同步生成阅读版。

## 如何复习

1. 从[复习清单](复习清单.md)选择主题，先尝试回答自测题。
2. 阅读“快速回顾”，再针对薄弱处重看原理、推导和项目应用。
3. 区分“能解释原理”“能选择方法”和“已在实机验证”，把仍不清楚的问题带回对应章节。
